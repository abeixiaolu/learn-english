## Part 1 复习抽查（5 min）

> 今天是第一天，做 3 道热身题，唤醒对 be 动词的印象。

1. 写出 be 动词在 I / he / they 后的形式。

答案：

```
I am
He is
They are
```

2. 「她是老师」用英文怎么说？（注意冠词）

答案：

```
She is a teacher.
```

3. 下面哪句更自然？为什么？
   - A) I am very tired after work.
   - B) I am tired after work.

答案：

```
B
```

解析：B 更自然。英文表状态时常直接用形容词，不必从中文「很累」硬加 very；A 口语里也能说，但 B 更贴近今天学的习惯。

## Part 2 语法复盘（10 min）

阅读 `grammar/01-be-verbs.md`，然后完成下面练习。

### 今日要点

1. **主系表**：主语 + be + 名词/形容词/介词短语。
2. **冠词**：单数可数名词前通常要加 a/an（I am **an** engineer）。
3. **形容词**：表状态时直接用形容词，不必从中文硬加「很」。
4. **疑问/否定**：be 提前或加 not——Are you busy? / I am not at home.
5. **自我介绍**：My name is … / I am a … / I am from …

### 练习

1. 填空：We ___ software engineers.（be 动词）

答案：

```
are
```

2. 改错：He is engineer. My colleague are nice.

答案：

```
He is an engineer. My colleague is nice.
```

3. 翻译：我来自杭州。

答案：

```
I am from Hangzhou.
```

4. 翻译：你今天忙吗？

答案：

```
Are you busy today?
```

5. 翻译：他们不在会议室。

答案：

```
They aren't at office.
```

正确答案：

```
They aren't in the meeting room.
```

解析：「会议室」是 meeting room，不是 office；in the meeting room 表在某个房间里。

## Part 4 回译练习（20 min）

把下面 **18 句中文** 译成英文。注意 be 动词、冠词，以及形容词前别硬加「很」。

1. 我是一名后端工程师。

答案：

```
I am a backend engineer.
```

2. 她是我的同事。

答案：

```
She is my colleague.
```

3. 我来自上海。

答案：

```
I am from Shanghai.
```

4. 你今天有空吗？

答案：

```
Are you available today?
```

5. 他现在很忙。

答案：

```
He is busy now.
```

6. 我们不在办公室。

答案：

```
We aren't at office.
```

正确答案：

```
We aren't in the office.
```

解析：office 是可数名词，要说 in the office 或 at the office，不能省略 the。

7. 他们在开远程会议。

答案：

```
They are on a remote meeting.
```

正确答案：

```
They are in a remote meeting.
```

解析：「开会」用 in a meeting；on a remote call 也可以说，但不说 on a meeting。

8. 你专注吗？（提醒：Are you focused?）

答案：

```
Are you focused?
```

9. 我叫 Alex，是一名前端工程师。

答案：

```
My name is Alex, I am a frontend engineer.
```

正确答案：

```
My name is Alex. I am a frontend engineer.
```

解析：两个完整句子不能用逗号直接连接（comma splice），应拆成两句或加 and。

10. 这位是我的新同事。

答案：

```
This is my new colleague.
```

11. 会议在三点，我现在有空。

答案：

```
The meeting is at three, I am available now.
```

正确答案：

```
The meeting is at three. I am available now.
```

解析：两个独立句子应分开写，或用句号隔开，避免 comma splice。

12. 他不在工位上。

答案：

```
He isn't at work station.
```

正确答案：

```
He isn't at his desk.
```

解析：「工位」口语常用 desk；workstation 前需加 his/my 等物主词。

13. 我们是同一个团队的。

答案：

```
We are same team.
```

正确答案：

```
We are on the same team.
```

解析：「同一个团队」固定搭配是 on the same team，不是 are same team。

14. 你今天累吗？

答案：

```
Are you tired today?
```

15. 我不累，但有点忙。

答案：

```
I am not tired, but i am busy.
```

正确答案：

```
I am not tired, but I am a bit busy.
```

解析：I 永远大写；「有点忙」用 a bit busy 比单说 busy 更贴切。

16. 产品经理现在在会议室吗？

答案：

```
Is product manager at office now?
```

正确答案：

```
Is the product manager in the meeting room now?
```

解析：特指那位 PM 要加 the；会议室是 meeting room，不是 office。

17. 是的，她正在会上，暂时没空。

答案：

```
Yes, she is on meeting and isn't available.
```

正确答案：

```
Yes, she is in a meeting and isn't available right now.
```

解析：「在开会」固定说 in a meeting，不说 on meeting；「暂时」可加 right now。

18. 很高兴认识你，我是新来的工程师。

答案：

```
Nice to meet you, I am a new engineer.
```

## 错题回顾

### 冠词缺失

- Part 2-5「他们不在会议室」：❌ They aren't at office → ✅ They aren't in the meeting room
- Part 4-6「我们不在办公室」：❌ We aren't at office → ✅ We aren't in the office
- Part 4-16「产品经理在会议室吗」：❌ Is product manager at office → ✅ Is the product manager in the meeting room

**规则**：特指的人/场所前加 the；可数单数名词不能省略冠词。

### 介词搭配

- Part 4-7「他们在开远程会议」：❌ on a remote meeting → ✅ in a remote meeting
- Part 4-13「同一个团队」：❌ We are same team → ✅ We are on the same team
- Part 4-17「正在会上」：❌ on meeting → ✅ in a meeting

**规则**：记固定搭配——in a meeting、on the same team；举一反三：on a remote **call** 也可以说，但不说 on a meeting。

### Comma splice

- Part 4-9「我叫 Alex…」：❌ My name is Alex, I am… → ✅ My name is Alex. I am…
- Part 4-11「会议在三点…」：❌ The meeting is at three, I am… → ✅ The meeting is at three. I am…

**规则**：两个完整句之间用句号或连词，不能只用逗号连接。

### 词汇场景

- Part 2-5 / Part 4-16：❌ office（办公室）→ ✅ meeting room（会议室）
- Part 4-12「工位」：❌ at work station → ✅ at his desk

**规则**：office ≠ 会议室；工位口语用 desk。

### 细节

- Part 4-15：❌ but i am busy → ✅ but I am a bit busy
- Part 1-3：只选了 B，未写原因

**规则**：I 永远大写；「有点」用 a bit；问「为什么」的题要简要解释。
