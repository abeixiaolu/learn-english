## Part 2 语法复盘

### 1. 状态、习惯、过去与正在发生

说身份、状态和位置，用 am / is / are：I 配 am，he / she / it 或单个人、物配 is，you / we / they 和复数配 are。形容词前不再加动作动词。例句：`The printer is available.`（打印机可用。）

说习惯，用一般现在时；第三人称单数的动作动词通常加 -s / -es，用了 does / doesn't 后恢复原形。usually 一般放在动作动词前、be 后。例句：`This script usually runs at night.`（这个脚本通常在夜间运行。）

说过去发生的动作，肯定句用过去式，如 write → wrote、find → found、send → sent；did / didn't 后用原形。说正在做，用 be + 动作的 -ing；still 表示还、仍然，通常放在 be 后。need、know 等状态动词通常不用进行时。

### 2. 名词、冠词、数量与比较

限定词是 a、an、the、my、that 等放在名词前、说明哪个或谁的词。单数可数名词通常需要限定词：首次提到一个用 a / an，双方已知的对象常用 the；已有 my / this / that 时不再叠加冠词。a / an 按紧邻词的开头发音选择。

某处有东西用 there is / are；单数或不可数名词配 is，复数配 are。某人拥有东西用 have / has。例句：`There is a printer here.`（这里有一台打印机。）

many / much 表示很多，more 表示更多；fewer 配可数复数，less 配不可数名词。肯定句中 a lot of 很常用。比较两者时，形容词可能加 -er，或用 more + 形容词，不重复添加比较形式。例句：`This option is cheaper.`（这个选项更便宜。）

notebook 是纸质笔记本，laptop 是笔记本电脑；lobby 是大厅，cabinet 是柜子。先认准对象，再检查句型。

### 3. 义务、计划和 before

| 意思   | 常用结构                                  |
| ------ | ----------------------------------------- |
| 不做   | don't / doesn't + 动词原形                |
| 不必做 | don't / doesn't have to + 动词原形        |
| 禁止做 | mustn't + 动词原形                        |
| 应该做 | should + 动词原形                         |
| 必须做 | must + 动词原形；have / has to + 动词原形 |

can 用于能力或请求，后接原形。be going to 常表示事先已有计划；will 可表示临时决定或当场承诺。例句：`They are going to upgrade this server next month.`（他们打算下个月升级这台服务器。）

before 后可以接名词、动作的 -ing，或有自己主语和动词的完整句子。as part of the process 表示作为流程的一部分，可以放在句首或句末。

### 4. 时间与地点

| 类别           | 常用规则与示例                                              |
| -------------- | ----------------------------------------------------------- |
| 较大时段       | in + 年 / 月；in the morning / afternoon / evening          |
| 具体某天       | on + 星期 / 日期；on Sunday evening                         |
| 时刻与固定表达 | at 8:30；at noon；at midnight；at night                     |
| 直接使用的时间 | this afternoon；next week；last night；every day；yesterday |
| 内部           | in a drawer；in the meeting room                            |
| 表面或约定用法 | on the whiteboard；on the balcony                           |
| 位置点         | at my desk；at the entrance                                 |

on Saturdays 表示每逢周六，强调重复；on Saturday 常指某个周六，也可在习惯语境中使用。every Saturday 同样表示每周六，every 后用单数，前面不加 on。星期的复数 -s 与动词的三单 -s 是两回事。

yesterday 只说昨天，last night 特指昨晚；不要自行缩小时间范围。时间和地点可以同时出现，译后逐项核对。November（十一月）已在 Day 020 批改中讲过，今天只作复习。

### 5. 疑问结构与信息检查

- be 句：把 am / is / are 移到主语前。
- 普通动作：Do / Does / Did + 主语 + 动词原形。
- 情态动词：Can / Must / Should + 主语 + 动词原形。
- have to：Do / Does + 主语 + have to + 动词原形。
- 不缩写的 be 否定疑问：Is / Are + 主语 + not + 其余部分。

例句：`Does this script need more data?`（这个脚本需要更多数据吗？）写完检查主语是否一致，时间、地点和对象是否准确，还、不必、更多等意思是否保留，疑问句末尾是否有问号。

### 练习

1. 填空：There \_\_\_ (be) two files on this laptop.

答案：

```
are
```

2. 填空：She usually **_ (review) documents, but she _** (not / have to) review them today.

答案：

```
reviews, doesn't have to
```

3. 根据句意填空：We have **_ requests today, but we need _** time.（今天请求更少，但需要更多时间。）

答案：

```
fewer, more
```

4. 填入 in / on / at：The meeting is **_ Friday afternoon, _** 3 p.m.

答案：

```
on, at
```

5. 填空：Please double-check the data before \_\_\_ (submit) the report.

答案：

```
submitting
```

## Part 4 回译练习

1. 我今天上午有空，但我的同事很忙。

答案：

```
I am available this morning, but my colleague is busy.
```

2. 电梯里有一条通知。（第一次提到通知）

答案：

```
There is a notice in the elevator.
```

3. 柜子里有两本纸质笔记本，但没有任何笔记本电脑。

答案：

```
There are two notebooks in the cabinet, but there aren't any laptops.
```

4. 她通常每周一确认那份日程安排，但她今天不必确认它。

答案：

```
She usually confirms that schedule on Mondays, but she doesn't have to confirm it.
```

正确答案：

```
She usually confirms that schedule on Mondays, but she doesn't have to confirm it today.
```

解析：on Mondays、三单和“不必”均正确；后半句漏了“今天”，补上 today 才能限定今天没有确认义务。

5. 我们今天没有很多反馈，但比昨天有更多时间。

答案：

```
We don't have much feedback today, but we have more time than yesterday.
```

6. 这台笔记本电脑比那台更可靠。

答案：

```
This laptop is more reliable than that one.
```

7. 他昨天在阳台上发现了一个问题。（第一次提到问题；不要改成昨晚）

答案：

```
He found an issue in the balcony yesterday.
```

正确答案：

```
He found an issue on the balcony yesterday.
```

解析：在阳台上通常用 on the balcony；found、an issue 和 yesterday 均正确。

8. 他昨晚写了这份报告，但没有把它发给我。

答案：

```
He wrote this report last night, but he didn't send it to me.
```

9. 她现在还在大厅里等你。（用现在进行时）

答案：

```
She is still waiting for you in the lobby.
```

表达说明（不计错）：现在进行时结合 still 已能在当前语境中表达“现在还在等”，接受；也可在句末补 now，让“现在”更明确。

10. 你能明天下午两点在入口处等我吗？

答案：

```
Can you wait for me at the entrance tomorrow afternoon?
```

正确答案：

```
Can you wait for me at the entrance at 2 p.m. tomorrow?
```

解析：原答案保留了明天下午和入口处，但漏了“两点”，需要补上具体钟点。

11. 我们打算在十一月更新那条通知。

答案：

```
We are going to update that notice in November.
```

12. 我稍后会把那份日程安排发给你。（当场承诺）

答案：

```
I will send that schedule to you later.
```

13. 提交这份报告前，你应该再核对一遍这些数据。（before 后接提交动作）

答案：

```
You should double check these data before submitting this report.
```

书写提醒（不计错）：these data 是可接受的正式复数用法，before submitting 正确；double-check 本课统一加连字符。

14. 按照流程，她必须在周四上午申请批准。（用 as part of the process）

答案：

```
As part of the process, She must ask for approval on Thursday morning.
```

书写提醒（不计错）：流程表达、must 和 on Thursday morning 都正确；逗号后的 She 应小写为 she。

15. 你禁止访问那台服务器。

答案：

```
You mustn't access that server.
```

16. 她今天不必在食堂里等我们。

答案：

```
She doesn't have to wait for us in the cafeteria.
```

正确答案：

```
She doesn't have to wait for us in the cafeteria today.
```

解析：“不必”、人物和地点都正确，但漏译了“今天”，句末补 today。

17. 部署前，我们必须审查这些文件吗？（用 must 提问；before 后接部署动作）

答案：

```
Must we review these files before deploying?
```

18. 他现在不是在调试吗？（用不缩写的否定疑问句）

答案：

```
Is he not debugging now?
```

## 错题回顾

### 今天与具体钟点不能漏

标签：`信息-漏译`

- Part 4-4「……但她今天不必确认它」：❌ but she doesn't have to confirm it → ✅ but she doesn't have to confirm it today
- Part 4-10「你能明天下午两点在入口处等我吗？」：❌ Can you wait for me at the entrance tomorrow afternoon? → ✅ Can you wait for me at the entrance at 2 p.m. tomorrow?
- Part 4-16「她今天不必在食堂里等我们。」：❌ She doesn't have to wait for us in the cafeteria. → ✅ She doesn't have to wait for us in the cafeteria today.

**规则**：写完回头逐项核对“哪一天、哪个时段、几点”；具体到某天的义务不能只写成没有时间限制的“不必”。

### 阳台用 on

标签：`搭配-介词`

- Part 4-7「他昨天在阳台上发现了一个问题。」：❌ He found an issue in the balcony yesterday. → ✅ He found an issue on the balcony yesterday.

**规则**：表达在阳台上，记住 on the balcony，不按空间内部机械套用 in。
