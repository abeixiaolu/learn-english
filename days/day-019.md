## Part 2 语法复盘

### 1. 介词是什么：交代“什么时候、在哪里”

介词是放在名词或名词短语前面、说明关系的小词。比如 on my desk 中的 on 说明位置。今天学习 in、on、at 表达时间和地点；不要把中文的“在”一律译成同一个词。

时间可以先记：**in 看较大时段，on 看具体某天，at 看时刻**。地点可以先记：**in 看内部，on 看表面，at 看位置点**。这只是入门线索，固定搭配仍要单独记。

### 2. 时间：时段、某天、时刻

| 用法 | 规则                                   | 示例                                                   |
| ---- | -------------------------------------- | ------------------------------------------------------ |
| in   | 年、月、季节；泛指早上、下午、晚上     | in 2027；in June；in the morning / afternoon / evening |
| on   | 星期、日期；具体某天的早上、下午、晚上 | on Saturday；on May 6；on Sunday evening               |
| at   | 钟点；部分固定时间表达                 | at 7:15；at noon；at midnight；at night                |

例句：`They usually review documents in the evening.`（他们通常在晚上审查文档。）`The meeting is on Wednesday.`（会议在周三。）

night 泛指夜间时通常用 at night；morning、afternoon、evening 泛指一天中的时段时用 in the。指定“某天的上午”时，整个时间按具体某天处理。

### 3. this / next / last / every 前通常不加时间介词

表达 this morning、next week、last night、every day 时，通常直接使用，不在前面加 in / on / at。today、tomorrow、yesterday 单独作时间说明时也一样。

例句：`We will review the plan next month.`（我们计划下个月审查这个计划。）`I checked the file yesterday.`（我昨天检查了那个文件。）

一个句子也可以同时交代日期和时刻；每部分按自身规则表达，例如 `on Saturday at 7:15`。表达“明天几点”时 tomorrow 直接用，钟点前仍需介词。

### 4. 地点：里面、表面、位置点

| 用法 | 关注点                       | 示例                              |
| ---- | ---------------------------- | --------------------------------- |
| in   | 在一个空间、范围或容器内部   | in the meeting room；in a folder  |
| on   | 接触表面；也常用于设备或平台 | on the whiteboard；on this server |
| at   | 把地点当作位置点，不强调内部 | at the entrance；at my desk       |

`She is in the meeting room.` 强调她在会议室里面。at my desk 通常说人在工位；on my desk 通常说东西在桌面上。实际用法取决于要表达的关系，不能只按地点大小机械选择。

### 5. 写完再查：信息、数量、冠词

先核对题干的时间有没有全部保留，再核对动词、数量和限定词。much 是“很多”，more 是“更多”；不必做用 don't / doesn't have to。a / an 看后面紧邻词的开头发音；例如 a useful file 中 useful 的开头是辅音音素 /j/。

## Part 4 回译练习

1. 我中午有一个预约。

答案：

```
I have an appointment at noon.
```

2. 她午夜还在调试。（用现在进行时）

答案：

```
She is debugging at midnight.
```

正确答案：

```
She is still debugging at midnight.
```

解析：原句中的“还”表示动作仍在继续，需要加 still（仍然；还），放在 is 后、debugging 前；at midnight 和现在进行时都正确。

3. 我们周一上午有一个预约。

答案：

```
We have an appointment in the morning on Monday.
```

表达建议（不计错）：in the morning on Monday 能表达周一上午；更简洁常用的是 on Monday morning。

4. 我们打算在十月更新这份文档。

答案：

```
We are going to update this document in October.
```

5. 那份报告在抽屉里。

答案：

```
That report is in the drawer.
```

6. 那台显示器在架子上。

答案：

```
That monitor is on the shelf.
```

7. 我的同事现在在入口处等你。

答案：

```
My colleague is waiting for you at the entrance now.
```

8. 这条通知在白板上。

答案：

```
This notice is on the whiteboard.
```

9. 日历在我的桌上。

答案：

```
The calender is on my desk.
```

正确答案：

```
The calendar is on my desk.
```

解析：“日历”拼作 calendar；calender 是另一词，表示压光机，这里用词不对；on my desk 正确。

10. 你能在下午三点再核对一遍这些数据吗？

答案：

```
Can you double check this data at 3 in the afternoon.
```

书写提醒（不计错）：Can you 的疑问语序、at 3 in the afternoon 和 this data 都可接受；末尾应改为问号，double-check 本课统一加连字符。可写：Can you double-check this data at 3 in the afternoon?

11. 按照流程，我们必须在周五审查这些文件。（用 as part of the process）

答案：

```
We must review these files on Friday as part of the process.
```

12. 他通常在晚上准备报告。（泛指晚上，用 night）

答案：

```
He usually prepares the report at night.
```

13. 她今天下午不必提交这份报告。

答案：

```
She doesn't have to submit this report in the afternoon today.
```

表达建议（不计错）：in the afternoon today 可以理解为今天下午；更自然、简洁的是 this afternoon，直接作时间说明。

14. 我们今天上午需要更多反馈，但不需要很多数据。

答案：

```
We need more feedback in the morning today, but we don't need much data.
```

表达建议（不计错）：more feedback、much data 和时间信息都正确；in the morning today 更自然地写作 this morning。

15. 他昨天在登录流程中发现了一个问题。（第一次提到问题）

答案：

```
He found an issue in the login process yesterday.
```

16. 她通常在周二确认日程安排，但她今天不必确认。

答案：

```
She usually confirms schedule on Tuesday, but he doesn't have to confirm it today.
```

正确答案：

```
She usually confirms the schedule on Tuesdays, but she doesn't have to confirm it today.
```

解析：schedule 在这里是单数可数名词，指双方知道的日程安排时加 the；后半句的主语仍是“她”，应把 he 改为 she；on Tuesday 也可接受，on Tuesdays 更明确表示每逢周二。

17. 我们下周有一个预约。

答案：

```
We have an appointment next week.
```

18. 明天上午九点，我必须在入口处等你吗？（用 must 提问）

答案：

```
Must I wait for you at the entrance at 9 a.m. tomorrow.
```

书写提醒（不计错）：Must I、地点和时间表达均正确；疑问句末尾用问号：Must I wait for you at the entrance at 9 a.m. tomorrow?

## 错题回顾

### “还在做”要保留持续含义

标签：`信息-漏译`

- Part 4-2「她午夜还在调试。」：❌ She is debugging at midnight. → ✅ She is still debugging at midnight.

**规则**：现在进行时表示动作正在发生；“还、仍然”的持续含义可用 still 表达，通常放在 be 后、动作的 -ing 前。still 此前未在本课词表中列出，本题作为语义补充讲解。

### calendar 的拼写

标签：`拼写-普通词`

- Part 4-9「日历在我的桌上。」：❌ The calender is on my desk. → ✅ The calendar is on my desk.

**规则**：表示“日历”用 calendar，结尾是 -dar；calender 是不同的词。

### 单数可数名词需要限定词

标签：`冠词-特指`

- Part 4-16「她通常在周二确认日程安排……」：❌ She usually confirms schedule on Tuesday → ✅ She usually confirms the schedule on Tuesdays

**规则**：schedule 作单数可数名词时，前面需要 the、a、her 等限定词；确认双方知道的日程安排时通常用 the schedule。

### 前后主语要核对

标签：`信息-漏译`

- Part 4-16「……但她今天不必确认。」：❌ but he doesn't have to confirm it today → ✅ but she doesn't have to confirm it today

**规则**：逐个核对分句中的人物；这里是主语信息译错，而不是漏掉时间，she 不能变成 he。
