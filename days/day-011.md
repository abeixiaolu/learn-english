# Day 011 — 将来时 will / be going to

> 语法专题：`grammar/10-future.md`

---

## Part 1 复习抽查

1. 改错：This feedback is better than yesterday.

答案：

```
This feedback is better than yesterday's feedback.
```

2. 填空：He **_ (not respond) to any messages now, but he usually _** (respond) after standup.

答案：

```
He is not responding to any messages now, but he usually responds after standup.
```

3. 翻译：你要回复的消息比我多吗？

答案：

```
Do you have more messages to respond to than I do?
```

## Part 2 语法复盘

阅读 `grammar/10-future.md`，然后完成下面练习。

### 今日要点

1. **will + 动词原形**：常用于临时决定、承诺或预测。
2. **be going to + 动词原形**：常用于已有计划，或根据明显迹象做判断。
3. `will` 后不要加 `to`，也不要把后面的动词改成三单或过去式。
4. `be going to` 里的 `be` 要随主语变化：`am / is / are`。
5. 将来时间信号常见有 `tomorrow / next week / later / soon`。

### 练习

1. 选词填空（will / am going to）：临时决定：I **\_** join the call now.

答案：

```
will
```

2. 填空：已有计划：We **\_** release the hotfix tomorrow.

答案：

```
We are going to release the hotfix tomorrow.
```

3. 改错：She will going to prepare the report tomorrow.

答案：

```
She is going to prepare the report tomorrow.
```

4. 选词填空（will / is going to）：明显迹象：Look at the data. This plan **\_** need more time soon.

答案：

```
is going to
```

5. 改错：Can you respond this message later?

答案：

```
Will you respond this message later?
```

正确答案：

```
Can you respond to this message later?
```

解析：`respond to + 对象` 是固定搭配，改成将来疑问 `Will you...` 也可以，但介词 `to` 不能省。

## Part 4 回译练习

把下面 **18 句中文** 译成英文。注意：临时决定/承诺常用 `will`，已有计划或明显迹象常用 `be going to`。

1. 我现在会加入通话。

答案：

```
I will join the call now.
```

2. 我们明天打算发布这个热修复。

答案：

```
We are going to release the hotfix tomorrow.
```

3. 她下周打算准备这份报告。

答案：

```
She is going to prepare this report next week.
```

4. 他稍后会回复这条消息。

答案：

```
He will respond to this message later.
```

5. 我们很快会有一个计划。

答案：

```
We will have a plan soon.
```

6. 她明天会检查日程安排。

答案：

```
She will check the schedule tomorrow.
```

7. 我们打算明天升级预发服务器。

答案：

```
We are going to upgrade the staging server tomorrow.
```

8. 你明天会估算我们需要多少时间吗？

答案：

```
How much time will we need by your estimate?
```

正确答案：

```
Will you estimate how much time we need tomorrow?
```

解析：中文主语是「你」，动作是「估算」，并且时间词「明天」需要译出来。

9. 我们会在截止日期前收尾这份报告。

答案：

```
We will wrap up this report before deadline.
```

正确答案：

```
We will wrap up this report before the deadline.
```

解析：这里是双方明确的截止日期，`deadline` 前要加 `the`。

10. 这是今天最好的选项；我会选择它。

答案：

```
This is the best option today; I will choose it.
```

正确答案：

```
This is the best option for today; I will choose it.
```

解析：`the best option for today` 更自然，表示“就今天而言最合适的选项”。

11. 新计划会比旧计划更可靠吗？

答案：

```
Is the new plan more reliable than the old one?
```

正确答案：

```
Will the new plan be more reliable than the old one?
```

解析：中文里的「会」表示将来判断，要用 `will be` 或 `is going to be`。

12. 我们下周不会加班。

答案：

```
We won't work overtime next week.
```

13. 看这些数据，这个选项很快会更贵。

答案：

```
Look at this data, this option will be more expensive.
```

正确答案：

```
Look at the data. This option is going to be more expensive soon.
```

解析：有明显迹象时更适合用 `be going to`，并且「很快」要译成 `soon`；两个完整句不要只用逗号连接。

14. 我没有权限访问这些文件，所以我会稍后回复。

答案：

```
I don't have permission to access these files, so I will respond later.
```

15. 你会回复这条消息吗？

答案：

```
Will you respond to the message?
```

16. 他现在没有在准备报告；他打算稍后准备。

答案：

```
He doesn't prepare the report now; He is going to prepare it later.
```

正确答案：

```
He isn't preparing the report now; he is going to prepare it later.
```

解析：`now` 表示正在发生，要用现在进行时否定；分号后普通代词 `he` 不需要大写。

17. 昨天会议室里人更少，但明天会有更多人。

答案：

```
There were fewer people in the meeting room yesterday, but there are more people tomorrow.
```

正确答案：

```
There were fewer people in the meeting room yesterday, but there will be more people tomorrow.
```

解析：「明天会有」是将来时间，要用 `there will be` 或 `there are going to be`。

18. 我们没有更多时间，所以明天会选择更快的选项。

答案：

```
We don't have much time, so we will choose the faster option.
```

正确答案：

```
We don't have more time, so we will choose the faster option tomorrow.
```

解析：「没有更多时间」是 `don't have more time`，不是 `don't have much time`；「明天」也要译出来。

## 错题回顾

### 固定搭配介词

标签：`搭配-介词`

- Part 2-5「Can you respond this message later?」：❌ Will you respond this message later? → ✅ Can you respond to this message later?

**规则**：`respond to + 对象` 里的 `to` 不能省，疑问句里也要保留。

### 信息完整与自然表达

标签：`信息-漏译`、`表达-中式直译`

- Part 4-8「你明天会估算我们需要多少时间吗？」：❌ How much time will we need by your estimate? → ✅ Will you estimate how much time we need tomorrow?
- Part 4-10「这是今天最好的选项；我会选择它。」：❌ This is the best option today; I will choose it. → ✅ This is the best option for today; I will choose it.
- Part 4-18「我们没有更多时间，所以明天会选择更快的选项。」：❌ We don't have much time, so we will choose the faster option. → ✅ We don't have more time, so we will choose the faster option tomorrow.

**规则**：翻译时先锁定主语、时间词和限定语；`for today`、`more time` 这类细节会改变句子的自然度或原意。

### 将来时选择

标签：`信息-漏译`、`表达-中式直译`

- Part 4-11「新计划会比旧计划更可靠吗？」：❌ Is the new plan more reliable than the old one? → ✅ Will the new plan be more reliable than the old one?
- Part 4-13「看这些数据，这个选项很快会更贵。」：❌ Look at this data, this option will be more expensive. → ✅ Look at the data. This option is going to be more expensive soon.
- Part 4-17「昨天会议室里人更少，但明天会有更多人。」：❌ There were fewer people in the meeting room yesterday, but there are more people tomorrow. → ✅ There were fewer people in the meeting room yesterday, but there will be more people tomorrow.

**规则**：看到未来时间或「会」时要检查是否需要 `will`；看到明显迹象时优先用 `be going to`。

### 冠词与句子连接

标签：`冠词-特指`、`句式-逗号连接`

- Part 4-9「我们会在截止日期前收尾这份报告。」：❌ We will wrap up this report before deadline. → ✅ We will wrap up this report before the deadline.
- Part 4-13「看这些数据，这个选项很快会更贵。」：❌ Look at this data, this option will be more expensive. → ✅ Look at the data. This option is going to be more expensive soon.

**规则**：特指的截止日期用 `the deadline`；两个完整句子不要只用逗号连接。

### 现在进行时

标签：`时态-进行时`、`表达-中式直译`

- Part 4-16「他现在没有在准备报告；他打算稍后准备。」：❌ He doesn't prepare the report now; He is going to prepare it later. → ✅ He isn't preparing the report now; he is going to prepare it later.

**规则**：`now` 表示正在发生时用 `be + -ing`，分号后如果不是专有名词，普通代词不用大写。
