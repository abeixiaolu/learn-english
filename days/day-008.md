# Day 008 — 现在进行时 vs 一般现在时

> 语法专题：`grammar/07-present-continuous.md`

---

## Part 1 复习抽查

1. 填空：She \_\_\_ (can) access the staging server, but she \_\_\_ (not join) the call yesterday.

答案：

```
can, can't join
```

正确答案：

```
can, didn't join
```

解析：yesterday 要用过去时，否定是 didn't join，不是 can't join。

2. 改错：I found a issue in login flow. The issue blocks the login.

答案：

```
I found a issue in the login flow, the issue blocks the login.
```

正确答案：

```
I found an issue in the login flow. The issue blocks login.
```

解析：issue 前用 an；两个完整句不要只用逗号连接；login 表登录行为时通常不用 the。

3. 翻译：你能看一下这个 PR 吗？

答案：

```
Can you take a look at this PR?
```

## Part 2 语法复盘

阅读 `grammar/07-present-continuous.md`，然后完成下面练习。

### 今日要点

1. **现在进行时**：主语 + am / is / are + V-ing，表示正在做或当前阶段在做。
2. **对比一般现在时**：习惯、日常用一般现在时；此刻/当前用现在进行时。
3. **时间信号**：now / right now / at the moment / currently → 进行时；every day / usually / always → 一般现在时。
4. **状态动词**：know / want / need / understand / like 等通常不用进行时。
5. **纠偏**：不要把习惯动作写成进行时，也不要把状态动词写成进行时。

### 练习

1. 填空：I \_\_\_ (fix) a bug right now. She \_\_\_ (review) PRs every morning.

答案：

```
I am fixing a bug right now. She reviews PRs every morning.
```

2. 填空：They \_\_\_ (deploy) the service at the moment. We \_\_\_ (deploy) to staging every Friday.

答案：

```
They are deploying the service at the moment. We deploy to staging every Friday.
```

3. 改错：He is knowing the root cause. I am needing your help now.

答案：

```
He is knowing the root cause. I need your help now.
```

正确答案：

```
He knows the root cause. I need your help now.
```

解析：know / need 是状态动词，一般不用进行时；两处都要改成一般现在时。

4. 改错：She check the logs now. I am writing unit tests every week.

答案：

```
She is checking the logs now. I write unit tests every week.
```

5. 翻译：你现在在等构建结果吗？

答案：

```
Are you waiting the build result now?
```

正确答案：

```
Are you waiting for the build now?
```

解析：wait for + 名词，for 不能省；说 the build 即可。

## Part 4 回译练习

把下面 **18 句中文** 译成英文。注意区分：**正在做**用现在进行时，**习惯**用一般现在时；状态动词不用进行时。

1. 我现在正在修一个 bug。

答案：

```
I am fixing a bug right now.
```

2. 她此刻正在审查这个 PR。

答案：

```
She is reviewing this PR right now.
```

3. 他们此刻正在迁移数据库。

答案：

```
They are migrating the database right now.
```

4. 你现在在等构建结果吗？

答案：

```
Are you waiting for the build result now?
```

5. 他现在没有在写文档。

答案：

```
They aren't writing the document now.
```

正确答案：

```
He isn't writing a document now.
```

解析：中文是「他」，主语用 He；第一次提到一份文档用 a document 更自然。

6. 我通常每天早上检查日志。

答案：

```
I usually check the logs every morning.
```

7. 她现在正在检查日志。

答案：

```
She is checking the logs right now.
```

8. 我现在不能加班。

答案：

```
I am not working overtime now.
```

正确答案：

```
I can't work overtime now.
```

解析：「不能」表能力/许可，用 can't，不是现在进行时的否定。

9. 我正在处理一个热修复。

答案：

```
I am working on a hotfix now.
```

10. 我知道根本原因。

答案：

```
I know the root cause.
```

11. 我现在需要你的帮助。

答案：

```
I need your help now.
```

12. 她理解这个问题。

答案：

```
She understand this issue.
```

正确答案：

```
She understands this issue.
```

解析：一般现在时第三人称单数要加 -s：understands。

13. 她正在回复一封客户邮件。

答案：

```
She is replying a customer email now.
```

正确答案：

```
She is responding to a customer email now.
```

解析：今天词表是 respond to；若用 reply 也要加 to：replying to。

14. 我正在深入排查登录问题。

答案：

```
I am digging into the login issue now.
```

15. 他正在调试这个 API。

答案：

```
He is debugging this API now.
```

16. 她现在正在做回滚。

答案：

```
She is doing a rollback now.
```

17. 我正在收尾这份报告。

答案：

```
I am wrapping up this report now.
```

18. 你能看一下这个 PR 吗？她现在正在复现那个 bug。

答案：

```
Can you take a look at this PR? She is reproducing that bug now.
```

## 错题回顾

### 时态混用

标签：`时态-过去式`、`表达-中式直译`

- Part 1-1「she _ (not join) the call yesterday」：❌ can't join → ✅ didn't join
- Part 2-3「He is knowing…」：❌ He is knowing the root cause → ✅ He knows the root cause
- Part 4-8「我现在不能加班」：❌ I am not working overtime now → ✅ I can't work overtime now

**规则**：看到 yesterday 用过去时；know/need 等状态动词不用进行时；「不能」优先用 can't，不要写成 am not doing。

### 冠词与句子连接

标签：`冠词-a-an`、`冠词-特指`、`句式-逗号连接`

- Part 1-2「I found a issue…」：❌ I found a issue in the login flow, the issue blocks the login. → ✅ I found an issue in the login flow. The issue blocks login.

**规则**：元音音开头用 an；两个完整句用句号分开；login 表行为时通常不加 the。

### 介词搭配

标签：`搭配-介词`

- Part 2-5「等构建结果」：❌ waiting the build result → ✅ waiting for the build
- Part 4-13「回复一封客户邮件」：❌ replying a customer email → ✅ responding to / replying to a customer email

**规则**：wait for、respond to、reply to，介词不能省。

### 主语与三单

标签：`信息-漏译`、`时态-三单`

- Part 4-5「他现在没有在写文档」：❌ They aren't writing… → ✅ He isn't writing…
- Part 4-12「她理解这个问题」：❌ She understand → ✅ She understands

**规则**：主语要和中文一致；一般现在时 he/she/it 后动词加 -s。
