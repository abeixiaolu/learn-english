## Part 2 语法复盘

### 1. 转折与让步是什么

转折是把有反差的两件事放在一起，比如“报告很重要，但还没准备好”。让步是先承认一个情况，再说结果并没有按通常的预期发生，比如“虽然很忙，但仍然能帮忙”。

but 表示“但是”；although 表示“虽然”。它们与 because / so 不同：because / so 说明原因和结果，but / although 强调反差或“尽管如此”。

### 2. but 连接两个有反差的句子

结构：完整句子 + , but + 完整句子。

This report is important, but it is not ready yet.（这份报告很重要，但是还没有准备好。）

今天先练两边都有主语和谓语的完整形式。but 后仍然要说明“谁做什么”或“什么是什么状态”，不能只留下形容词而漏掉主语和 be。

### 3. although 后接完整句子

结构：Although + 完整句子, + 完整句子。

Although the printer is old, it still works.（虽然打印机旧了，但它仍然能用。）

old 表示“旧的”，works 在这里表示“能运转”。although 后的部分先承认一个情况，后面的主句再说重点；主句就是去掉 although 引导的部分后，仍能独立表达意思的句子。although 放在句首时，这一部分结束后通常加逗号。

也可以把 although 放后面：The printer still works although it is old.（打印机虽然旧了，但仍然能用。）这种顺序下，紧密相连的 although 部分前通常不加逗号。今天的练习会指定顺序。

### 4. 同一组“虽然……但是……”选一种连接方式

中文常同时说“虽然”和“但是”，英文表达同一组让步关系时，用 although 引出让步部分，主句直接接下去；或者只用 but 连接两句。

例如“她很忙，但仍然能帮我”可以写：She is busy, but she can still help me. 也可以写：Although she is busy, she can still help me.

换连接词时保留句意和全部信息，不要把“有反差”改成“有因果”。still 表示“仍然”，只有题意需要时才使用，不因使用 although 就自动添加。

### 5. 新连接词不改变简单句规则

每个分句分别检查主语、be、动作动词和时间。形容词表达状态仍需要 be；情态动词后仍用动词原形。用 it / they 指回前面明确提过的对象，地点状态也可以直接写地点名词。

### 练习

按指定连接方式作答，保留全部信息。

1. 用 but 连接，顺序不变：The report is ready. We cannot send it today.

答案：

```
The report is ready, but we cannot send it today.
```

2. 用 although 连接，把第一句放在 Although 后：She has many meetings today. She can help us this afternoon.

答案：

```
Although she has many meetings today, she can help us this afternoon.
```

3. 改成 Although 开头的句子，保留全部信息：The connection is slow, but we can join the call now.

答案：

```
Although the connection is slow, we can join the call now.
```

4. 填入括号中词的正确形式：Although he **_ (be) busy every morning, he _** (review) the calendar every day.

答案：

```
is, reviews
```

## 错题回顾

### 可供使用与功能正常

标签：`语义-词义`

- Part 4-7「这个麦克风很旧，但是它仍然能用」：❌ it is still available → ✅ it still works。

**规则**：available 表示有空、可获得或可供使用；work 表示机器能正常运转。描述旧设备仍然能用时，still works 更准确。这是词义问题，不是 but 的语法问题。
