## Part 2 语法复盘

阅读 `grammar/03-articles.md`，然后完成下面练习。

### 今日要点

1. **a / an**：第一次提到、泛指「某一个」；看发音选 a 还是 an。
2. **the**：双方已知、特指「那个」——the office, the product manager。
3. **第一次 → a/an，再次 → the**：I found **a** bug. **The** bug is critical.
4. **零冠词**：复数/不可数泛指、专有名词——Bugs happen. / I need help.
5. **中文无冠词，英文常要补**：不要漏掉 a / the。

### 练习

1. 填空：I am **_ engineer. She is _** product manager on our team.（两个空）

答案：

```
I am an engineer. She is a product manager on our team.
```

2. 改错：We deploy to test environment every day. He writes weekly report on Friday.

答案：

```
We deploy to the test environment every day. He writes a weekly report on Friday.
```

3. 选词填空（a / an / the / Ø）：I saw **_ bug yesterday. _** bug is still open.

答案：

```
I saw a bug yesterday. The bug is still open.
```

4. 翻译：你在办公室吗？

答案：

```
Are you at the office?
```

5. 翻译：我需要一台新笔记本电脑。

答案：

```
I need a new laptop.
```

## Part 4 回译练习

把下面 **18 句中文** 译成英文。注意：**第一次提到用 a/an，特指/已知用 the**；可数单数名词前别漏冠词。

1. 我是一名软件工程师。

答案：

```
I am a soft engineer.
```

正确答案：

```
I am a software engineer.
```

解析：软件工程师是 software engineer，soft 是「柔软的」，不能缩写。

2. 她是我们团队的产品经理。

答案：

```
She is a product manager in our team.
```

正确答案：

```
She is the product manager on our team.
```

解析：「我们团队的那位 PM」用 the 更贴切；团队搭配是 on our team，不是 in our team。

3. 我在日志里发现了一个 bug。

答案：

```
I found a bug in logs.
```

正确答案：

```
I found a bug in the logs.
```

解析：特指那些日志要加 the——in the logs / in the log。

4. 这个 bug 会挡住登录。

答案：

```
This bug will cover the login.
```

正确答案：

```
The bug blocks login.
```

解析：「挡住」用 block，不用 cover（覆盖）；今天练冠词时，前文已提过可用 The bug。

5. 请为这个问题开一张工单。

答案：

```
Please open a ticket for this issue.
```

6. 工单已经在你的收件箱里。

答案：

```
The ticket is in your inbox.
```

7. 我们今天下午有一个会议。

答案：

```
We have a meeting in the afternoon.
```

正确答案：

```
We have a meeting this afternoon.
```

解析：「今天下午」用 this afternoon；in the afternoon 只表一般「在下午」。

8. 会议在三点开始。

答案：

```
The meeting starts at 3 p.m.
```

9. 你在办公室吗？

答案：

```
Are you at the office?
```

10. 产品经理现在在会议室。

答案：

```
The product manager is in the meeting room now.
```

11. 他每周五写一份周报。

答案：

```
He writes a weekly report every Friday.
```

12. 后端团队每天部署到测试环境。

答案：

```
The backend team deploys to the test environment every day.
```

13. 我需要一台新笔记本电脑。

答案：

```
I need a new laptop.
```

14. 笔记本电脑在我的工位上。

答案：

```
The laptop is on my desk.
```

15. 她给团队分享了一份文档。

答案：

```
She shared a document to the team.
```

正确答案：

```
She shared a document with the team.
```

解析：share 的固定搭配是 share something with someone，不用 to。

16. 文档在共享盘里。

答案：

```
The document is in shared drive.
```

正确答案：

```
The document is in the shared drive.
```

解析：特指那个共享盘，要加 the——in the shared drive。

17. 那是目前最好的方案。

答案：

```
That is the best solution so far.
```

18. 工程师会写代码，但也会修 bug。

答案：

```
Engineers not only write code, bug also fix bugs.
```

正确答案：

```
Engineers write code, but they also fix bugs.
```

解析：复数泛指 Engineers 前零冠词正确；后半句应是 but they also fix bugs，not only…but also 不能拆成 bug also。

## 错题回顾

### 特指漏 the

- Part 4-3「在日志里发现了一个 bug」：❌ in logs → ✅ in the logs
- Part 4-16「文档在共享盘里」：❌ in shared drive → ✅ in the shared drive

**规则**：听者知道是哪批日志/哪个盘时，加 the；类似还有 in the office、in the meeting room。

### 介词与固定搭配

- Part 4-2「我们团队的产品经理」：❌ in our team → ✅ on our team（且用 the product manager）
- Part 4-15「给团队分享文档」：❌ share … to the team → ✅ share … with the team
- Part 4-4「挡住登录」：❌ cover the login → ✅ block login / blocks login

**规则**：记整块——on the team、share with、block；不要用中文介词硬套 to/in。

### 时间表达

- Part 4-7「今天下午有一个会议」：❌ in the afternoon → ✅ this afternoon

**规则**：特指「今天的下午」用 this afternoon；in the afternoon 表一般习惯。

### 词汇与句式

- Part 4-1「软件工程师」：❌ soft engineer → ✅ software engineer
- Part 4-18「也会修 bug」：❌ not only write code, bug also fix → ✅ write code, but they also fix bugs

**规则**：software 不能缩成 soft；并列用 but they also…，not only…but also 要成对出现。
