## Part 1 复习抽查

1. 选词填空（don't have to / shouldn't）：不必加班：She **\_** work overtime today.

答案：

```
don't have to
```

正确答案：

```
doesn't have to
```

解析：意思选对了，「不必」用 `have to` 的否定；主语是 `She`，要用 `doesn't have to`。

2. 改错：Doesn't she working on this ticket now?

答案：

```
Isn't she working on this ticket now?
```

3. 改错：Why you didn't respond this message?

答案：

```
Why didn't you respond this message?
```

正确答案：

```
Why didn't you respond to this message?
```

解析：助动词提前是对的；`respond to + 对象` 里的 `to` 不能省。

4. 填空：They **_ (follow) the process every week, but they _** (not follow) it yesterday.

答案：

```
follow, didn't follow
```

5. 翻译：她还没有确认这个延迟。

答案：

```
She didn't confirm the delay yet.
```

## Part 2 语法复盘

复习 `grammar/07-present-continuous.md` 到 `grammar/12-questions-negation.md`，重点看下面 6 组句型。

### 语法要点回顾

1. **现在进行时 vs 一般现在时**：`now / right now / at the moment` 且表示正在做，用 `am / is / are + -ing`；`usually / every day` 表示习惯，用一般现在时。
2. **可数 / 不可数**：`data / feedback / permission / time` 不能用 `a / these` 一个一个数；肯定句常用 `some`，否定和疑问常用 `any`。
3. **比较级 / 最高级**：两者比较用 `faster / better / more efficient + than`；范围内“最……”用 `the best`。不要写 `more better`。
4. **will vs be going to**：临时决定、承诺常用 `will`；已经计划好的事，或眼前迹象很明显，常用 `be going to`。
5. **should / must / have to**：`should` 是建议，`must` 语气最强，`have to` 是外部安排。`don't have to` 是不必做，不是不该做。
6. **疑问句与否定句**：`submit / confirm` 这类动作动词要请 `do / does / did` 帮忙；`be` 和 `can / will / should / must` 自己提前，不要再加 `do`。

### 混合提醒

1. 看到 `now` 且正在发生：疑问句把 `is / are` 提前，不要写成 `doesn't + -ing`。
2. 有 `yesterday` 才用 `Did / didn't / missed`；没有过去时间，问习惯用 `Do / Does`。
3. 「还没有」在否定句里要把 `yet` 译出来。
4. `respond to` 里的 `to` 不能省；「回复我」用 `get back to me`。
5. 先锁定主语和动词：「我」不是 `we`，「升级」是 `upgrade`，「更新」才是 `update`。
6. 两个完整句子不要只用逗号连接。

## Part 4 回译练习

把下面 **18 句中文** 译成英文。注意混合使用前 6 天的语法：正在做 vs 习惯、可数/不可数、比较、will / be going to、should / must / have to、疑问与否定。

1. 我此刻正在处理这个工单。

答案：

```
I am working on this ticket at the moment.
```

2. 他通常在站会后回复消息，但他现在没有在回复。

答案：

```
He usually responds to messages after standup, but he isn't responding to this message now.
```

正确答案：

```
He usually responds to messages after standup, but he isn't responding now.
```

解析：时态都对；后半句中文只说「没有在回复」，没有「这条消息」，不要自己补上 `this message`。

3. 他们现在在调试吗？

答案：

```
Are they debugging now?
```

4. 我们今天请求更少，但没有更多时间。

答案：

```
We have fewer requests today, but we don't have more time.
```

5. 她没有任何权限更新这份文档。

答案：

```
She doesn't have any permission to update this document.
```

6. 收件箱里有一些消息。

答案：

```
There are some messages in the inbox.
```

7. 这个脚本比旧脚本更快。

答案：

```
This script is faster than the old one.
```

8. 这个选项比上一个更高效。

答案：

```
This option is more efficient than the last one.
```

9. 这是今天最好的选项。

答案：

```
This is the best option for today.
```

10. 你稍后会回复我吗？

答案：

```
Will you get back to me later?
```

11. 我们下周打算升级预发服务器。

答案：

```
We are going to upgrade the staging server next week.
```

12. 看这些数据。这个计划很快会需要更多时间。

答案：

```
Look at the data. This plan will need more time soon.
```

正确答案：

```
Look at the data. This plan is going to need more time soon.
```

解析：句号分开两句是对的；「看这些数据」是眼前迹象，这时更常用 `be going to`，不只是 `will`。

13. 你应该再核对一遍这些数据。

答案：

```
You should double-check the data again.
```

正确答案：

```
You should double-check the data.
```

解析：`should` 和 `the data` 都对；`double-check` 已经是「再核对一遍」，不必再加 `again`。

14. 她今天不必加班。

答案：

```
She doesn't have to work overtime today.
```

15. 发布前我必须申请批准吗？

答案：

```
Do I have to ask for approval before the release?
```

16. 他们遵循这个流程吗？

答案：

```
Do they follow the process?
```

17. 她还没有提交这张工单。

答案：

```
She didn't submit this ticket yet.
```

18. 她现在没有在更新文档吗？

答案：

```
Isn't she updating this document now?
```

## 错题回顾

### 第三人称用 doesn't have to

标签：`时态-三单`

- Part 1-1「不必加班：She \_ work overtime today.」：❌ don't have to → ✅ doesn't have to

**规则**：意思选 `don't have to` 对了，但 `she / he / it` 要用 `doesn't have to`。

### respond to 的 to 不能省

标签：`搭配-介词`

- Part 1-3「Why you didn't respond this message?」：❌ Why didn't you respond this message? → ✅ Why didn't you respond to this message?

**规则**：疑问句里助动词提前之后，`respond to` 的 `to` 仍要留下。

### 不要补中文没有的信息

标签：`信息-漏译`

- Part 4-2「他通常在站会后回复消息，但他现在没有在回复。」：❌ ...but he isn't responding to this message now. → ✅ ...but he isn't responding now.

**规则**：前半句的 `messages` 不要自动塞进后半句；中文没说「这条」，就不要写 `this message`。

### 明显迹象用 be going to

标签：`表达-中式直译`

- Part 4-12「看这些数据。这个计划很快会需要更多时间。」：❌ This plan will need more time soon. → ✅ This plan is going to need more time soon.

**规则**：先有 `Look at the data` 这种眼前证据时，优先 `be going to`，不要一看到「会」就写 `will`。

### double-check 已含「再」

标签：`表达-中式直译`

- Part 4-13「你应该再核对一遍这些数据。」：❌ You should double-check the data again. → ✅ You should double-check the data.

**规则**：`double-check` = 再核对一遍，不必再加 `again`。
