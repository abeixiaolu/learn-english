## Part 2 语法复盘

### 1. 先分清「是什么、怎么样」和「做什么」

句子里「谁」是主语，比如 `I`、`she`；「做什么」是动作动词，比如你学过的 `review`、`update`。

说身份、状态或所在地点时，用 **谁 + be + 身份 / 状态 / 地点**。be 要跟着「谁」变化：`I` 配 `am`；`he / she / it` 配 `is`；`you / we / they` 配 `are`。

例如：`The report is ready.`（报告准备好了。）`We are from Beijing.`（我们来自北京。）

表达忙、累等状态要有 be；中文里的「很」不一定要译成 `very`。确实想强调程度时可以用 `very`。

说日常动作时，直接用动作动词，不在它前面多加 be。

### 2. be 的否定与提问

否定：**谁 + be + not + 其余内容**。`is not` 可以缩写成 `isn't`，`are not` 可以缩写成 `aren't`。

提问：把 **be 放到「谁」前面**，后面保留其余内容。

例如：`The script isn't ready.`（脚本还没准备好。）`Is the server available?`（服务器可用吗？）

### 3. 一般现在时：习惯与日常动作

一般现在时用于经常做的事或一般事实。`every day`（每天）、`usually`（通常）常提示日常习惯。

`I / you / we / they` 后用动作动词原形；`he / she / it` 或一个人、一件东西后，动词通常加 `-s` 或 `-es`。这叫「第三人称单数」，先认主语，不必死记术语。

例如：`They deploy every week.`（他们每周部署。）`He reviews reports.`（他审查报告。）

提问或否定需要 `do / does` 帮忙。它们在这里叫助动词，就是帮助句子提问或否定的小词。

- 提问：**Do / Does + 谁 + 动词原形 + 其余内容？**
- 否定：**谁 + don't / doesn't + 动词原形 + 其余内容。**

`he / she / it` 用 `does / doesn't`，其他上述主语用 `do / don't`。用了 `does / doesn't`，后面的动作动词就恢复原形。

`usually` 放在动作动词前；如果句子用 be，则放在 be 后。

### 4. 冠词：一个，还是已知的那个

冠词是放在名词前的小词，比如 `a / an / the`。名词是人或东西的名称，你学过的 `engineer`、`laptop` 都是名词。

可以一件一件数的东西叫可数名词；单数指一件，复数指多件。单个可数名词通常需要 `a / an / the / my / this` 等限定，不能光着写。

- 不特指的一个、首次引入一个：通常用 **a / an**。
- 双方知道是哪一个、前面已经提到的那个：通常用 **the**。
- `a / an` 看紧接着的发音：辅音音用 `a`，元音音用 `an`。
- 已有 `my / this` 等时，不再叠加冠词。

例如：`a ticket`、`an option`、`my colleague`。别只看首字母，例如 `user` 开头发 /j/，要用 `a`。

### 5. 某处有东西：there is / there are

说「某处有……」用 **There is / are + 东西 + 地点**；说「某人拥有……」用 `have / has`。

一个东西用 `is`，多个东西用 `are`。例如：`There is a printer here.`（这里有一台打印机。）

否定在 `is / are` 后加 `not`；提问把 `is / are` 放到 `there` 前面。`some` 表示一些；这类句子的否定和提问通常用 `any`。

## 错题回顾

### 日常动作肯定句别漏第三人称 -s

标签：`时态-三单`

- Part 4-8「她通常更新文档。」：❌ She usually update the document. → ✅ She usually updates the document.

**规则**：he / she / it 后，日常动作肯定句的动词通常加 -s；用了 does / doesn't 时才恢复原形。

### 找回「开会」的英文搭配

标签：`词汇-遗忘`

- Part 4-12「你每天开会吗？」：❌ Do you 开会 every day? → ✅ Do you have meetings every day?

**规则**：「开会」可用 have a meeting / have meetings；这里问每天的习惯，用 have meetings 自然，也接受其他符合原意的正确表达。

### 桌面上用 on

标签：`搭配-介词`

- Part 4-14「我有一台笔记本电脑。这台电脑在我的桌上。」：❌ The laptop is in my desk. → ✅ The laptop is on my desk.

**规则**：on my desk = 在桌面上；in my desk = 在桌子内部，如抽屉里。
