# Day 012 — should / must / have to

> 语法专题：`grammar/11-modals.md`

---

## Part 1 复习抽查

1. 改错：Can you respond this message later?

答案：

```
Can you respond to this message later?
```

2. 填空：He **_ (not prepare) the report now; he _** (prepare) it later.

答案：

```
He isn't preparing the report now; he is going to prepare it later.
```

3. 翻译：我们没有更多时间，所以明天会选择更快的选项。

答案：

```
We don't have more time, so we will choose the faster option tomorrow.
```

## Part 2 语法复盘

阅读 `grammar/11-modals.md`，然后完成下面练习。

### 今日要点

1. **should + 动词原形**：建议、劝告，语气较弱。
2. **must + 动词原形**：必须/禁止，语气通常最强。
3. **have to / has to + 动词原形**：外部规定或客观安排带来的义务。
4. `don't / doesn't have to` = 不必做；`mustn't` = 禁止做。
5. 三者后面都接动词原形，不要加 `to`（`have to` 里的 `to` 属于固定结构本身）。

### 练习

1. 选词填空（should / must）：建议：You **\_** double-check the data before the release.

答案：

```
should
```

2. 填空：外部安排：She **\_** prepare the report today.

答案：

```
has to
```

3. 改错：You must to ask for approval before the upgrade.

答案：

```
You must ask for approval before the upgrade.
```

4. 选词填空（don't have to / mustn't）：不必加班：You **\_** work overtime tonight.

答案：

```
don't have to
```

5. 改错：Will the new plan more reliable than the old one?

答案：

```
Will the new plan be more reliable than the old one?
```

## Part 4 回译练习

把下面 **18 句中文** 译成英文。注意：建议用 `should`，强规则/强烈必要用 `must`，外部安排用 `have to`；`don't have to` 是不必，`mustn't` 是禁止。

1. 你应该先检查日程安排。

答案：

```
You should check the schedule first.
```

2. 我们必须在截止日期前完成这件事。

答案：

```
We must finish this before the deadline.
```

3. 她今天必须准备这份报告。

答案：

```
She has to prepare this report today.
```

4. 你今晚不必加班。

答案：

```
You don't have to stay late tonight.
```

5. 我们应该更新这份文档。

答案：

```
We should update this document.
```

6. 发布前你必须申请批准。

答案：

```
You must ask for approval before the release.
```

7. 他三点必须加入通话。

答案：

```
He must join the call at three o'clock.
```

8. 你应该再核对一遍这些数据。

答案：

```
You should double-check the data.
```

9. 我们必须遵循这个流程。

答案：

```
We must follow the process.
```

10. 我今天必须提交这张工单。

答案：

```
We must submit this ticket today.
```

正确答案：

```
I must submit this ticket today.
```

解析：主语是「我」，要用 `I`，不要写成 `We`；用 `have to` 也可以：`I have to submit this ticket today.`

11. 没有审查，你不应该部署。

答案：

```
You shouldn't deploy without review.
```

12. 她不必晚走。

答案：

```
She shouldn't stay late.
```

正确答案：

```
She doesn't have to stay late.
```

解析：「不必」是没有义务，用 `doesn't have to`；`shouldn't` 是「不该」，意思不同。

13. 我们今天必须升级预发服务器吗？

答案：

```
Must we update the staging server today?
```

正确答案：

```
Must we upgrade the staging server today?
```

解析：「升级」是 `upgrade`，不是 `update`（更新）；也可用 `Do we have to upgrade the staging server today?`

14. 我应该选择这个选项吗？

答案：

```
Should I choose this option?
```

15. 你必须回复这条消息。

答案：

```
You must respond to this message.
```

16. 他现在没有在准备报告；他应该稍后准备。

答案：

```
He isn't preparing the report now. He should prepare it later.
```

17. 我们没有更多时间，所以必须选择更快的选项。

答案：

```
We don't have more time, so we must choose the faster option.
```

18. 看这些数据。你应该在截止日期前收尾。

答案：

```
Look at the data. You should wrap up before the deadline.
```

## 错题回顾

### 主语与用词要贴中文

标签：`信息-漏译`

- Part 4-10「我今天必须提交这张工单。」：❌ We must submit this ticket today. → ✅ I must submit this ticket today.
- Part 4-13「我们今天必须升级预发服务器吗？」：❌ Must we update the staging server today? → ✅ Must we upgrade the staging server today?

**规则**：先锁定主语和核心动词；「我」≠ `we`，「升级」用 `upgrade`，「更新」才用 `update`。

### don't have to ≠ shouldn't

标签：`表达-中式直译`

- Part 4-12「她不必晚走。」：❌ She shouldn't stay late. → ✅ She doesn't have to stay late.

**规则**：`don't / doesn't have to` = 不必做；`shouldn't` = 不该做；`mustn't` = 禁止做。
