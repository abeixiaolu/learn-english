## Part 1 复习抽查

1. 改错：I need some permissions to access these files.

答案：

```
I need Permission to access these files.
```

正确答案：

```
I need permission to access these files.
```

解析：`permission` 是不可数名词，去掉 `some` 并改成单数形式正确；普通名词句中不要大写。

1. 填空：He **_ (not respond) to any messages now, but he usually _** (respond) after standup.

答案：

```
He isn't respond to any messages now, but he usually respond to after standup.
```

正确答案：

```
He isn't responding to any messages now, but he usually responds after standup.
```

解析：`now` 用现在进行时 `isn't responding`；`usually` 用一般现在时三单 `responds`，后面直接接 `after`，不要再加多余的 `to`。

1. 翻译：昨天会议室里没有很多人，但我们有一点时间讨论这个问题。

答案：

```
There weren't many people in the meeting room yesterday, but we had a little time to discuss this issue.
```

## Part 2 语法复盘

阅读 `grammar/09-comparatives.md`，然后完成下面练习。

### 今日要点

1. **比较级**用于两者比较，常见结构是 `A + be + 比较级 + than + B`。
2. 短形容词常加 `-er`：`fast → faster`、`easy → easier`、`hard → harder`。
3. 较长形容词常用 `more + 形容词`：`more reliable`、`more efficient`。
4. `good` 的比较级是 `better`，最高级是 `the best`，不要写 `more better`。
5. **最高级**通常用 `the + 最高级`，表示一个范围里“最……”的对象。

### 练习

1. 选词填空（faster / more faster）：This script is than the old script.

答案：

```
faster
```

1. 填空：This option is (easy) than that one, but this issue is (hard) than the last one.

答案：

```
easier, harder
```

1. 改错：This option is more better than the last one.

答案：

```
This option is better than the last one.
```

1. 填空：This is (good) option for today.

答案：

```
the best
```

1. 改错：Can you respond this message? I don't have any permission to access the file.

答案：

```
Can you respond to this message? I don't have permission to access the file.
```

## Part 4 回译练习

把下面 **18 句中文** 译成英文。注意：两者比较用比较级 + `than`；三个或以上中“最……”用 `the best / the most...`。

1. 这个脚本比旧脚本更快。

答案：

```
This script is faster than the old one.
```

1. 这个脚本比那个脚本更慢。

答案：

```
This script is slower than that script.
```

1. 这个问题比昨天的问题更容易。

答案：

```
This issue is easier than yesterday.
```

正确答案：

```
This issue is easier than yesterday's issue.
```

解析：比较对象要对齐：比的是「昨天的问题」，不是「昨天」这个时间，用 `yesterday's issue` 或 `the one yesterday`。

1. 这个问题比那个问题更难。

答案：

```
This issue is harder than that issue.
```

1. 这个选项比旧选项更便宜。

答案：

```
This option is cheaper than the old option.
```

1. 这个选项比那个选项更贵。

答案：

```
This option is more expensive than that option.
```

1. 预发服务器比测试环境更可靠。

答案：

```
The staging server is more reliable than the test server.
```

正确答案：

```
The staging server is more reliable than the test environment.
```

解析：中文是「测试环境」，对应 `test environment`，不是 `test server`。

1. 这个选项比上一个选项更高效。

答案：

```
This option is more efficient than the last one.
```

1. 这个选项比上一个选项更好。

答案：

```
This option is better than the last one.
```

1. 这是今天最好的选项。

答案：

```
This is the best option today.
```

正确答案：

```
This is the best option for today.
```

解析：固定说法更自然是 `the best option for today`，`for` 表示「就今天而言」。

1. 这份反馈比昨天的反馈更好。

答案：

```
This feedback is better than yesterday.
```

正确答案：

```
This feedback is better than yesterday's feedback.
```

解析：同第 3 句，要比的是「昨天的反馈」，用 `yesterday's feedback`，不要拿反馈和时间比。

1. 我们的数据比上周少。

答案：

```
Our data is less than last week.
```

正确答案：

```
We have less data than last week.
```

解析：更自然的说法是 `have less data`；`Our data is less than last week` 把数据和时间硬比，不自然。

1. 我今天需要的时间比昨天少。

答案：

```
I need less time than yesterday.
```

1. 这个方案需要的权限比旧方案少。

答案：

```
This solution needs less permission than the old one.
```

1. 你要回复的消息比我多吗？

答案：

```
Do you have more messages than me to respond to ?
```

正确答案：

```
Do you have more messages to respond to than I do?
```

解析：比较结构要把 `to respond to` 放在名词后，再用 `than I do`；问号前不要空格。

1. 昨天会议室里的人比今天少。

答案：

```
The person is more than yesterday in the meeting room.
```

正确答案：

```
There were fewer people in the meeting room yesterday than today.
```

解析：应用 `there be + fewer people` 描述人数；主语是复数 `people`，时间是昨天要用过去时。

1. 他现在没有在回复更多消息；他正在等更多反馈。

答案：

```
He do not respond to more messages now. He is waiting for more feedback.
```

正确答案：

```
He isn't responding to more messages now. He is waiting for more feedback.
```

解析：`now` 表示正在进行，用 `isn't responding`；`do not` 也未照顾到第三人称单数。

1. 我们有更少的请求，但没有更多时间。

答案：

```
We have fewer requests, but we have less time.
```

正确答案：

```
We have fewer requests, but we don't have more time.
```

解析：「没有更多时间」是 `don't have more time`，不是「有更少时间」`have less time`，信息被改写了。

## 错题回顾

### 比较对象要对齐，不要拿事物和时间硬比

标签：`表达-中式直译`、`信息-漏译`

- Part 4-3「这个问题比昨天的问题更容易。」：❌ This issue is easier than yesterday. → ✅ This issue is easier than yesterday's issue.
- Part 4-11「这份反馈比昨天的反馈更好。」：❌ This feedback is better than yesterday. → ✅ This feedback is better than yesterday's feedback.
- Part 4-12「我们的数据比上周少。」：❌ Our data is less than last week. → ✅ We have less data than last week.

**规则**：`than` 后面的对象要和主语同类；比「昨天的 X」用 `yesterday's X`，或改成 `have less/fewer + 名词`。

### 现在进行时与三单形态

标签：`时态-三单`、`时态-进行时`

- Part 1-2「He (not respond) to any messages now...」：❌ He isn't respond... usually respond to after... → ✅ He isn't responding... usually responds after...
- Part 4-17「他现在没有在回复更多消息…」：❌ He do not respond to more messages now. → ✅ He isn't responding to more messages now.

**规则**：有 `now` 且表示正在发生，用 `be + -ing`；一般现在时第三人称用 `responds / doesn't`。

### 人数与 there be；否定信息不要改写

标签：`表达-中式直译`、`信息-漏译`、`时态-过去式`

- Part 4-16「昨天会议室里的人比今天少。」：❌ The person is more than yesterday in the meeting room. → ✅ There were fewer people in the meeting room yesterday than today.
- Part 4-18「我们有更少的请求，但没有更多时间。」：❌ ...but we have less time. → ✅ ...but we don't have more time.

**规则**：说「有多少人」优先 `There is/are/were + people`；「没有更多」= `don't have more`，不要自动改成 `have less`。

### 搭配与用词精度

标签：`搭配-介词`、`信息-漏译`、`拼写-专有名词`

- Part 1-1「I need some permissions...」：❌ I need Permission... → ✅ I need permission...
- Part 4-7「预发服务器比测试环境更可靠。」：❌ ...than the test server. → ✅ ...than the test environment.
- Part 4-10「这是今天最好的选项。」：❌ This is the best option today. → ✅ This is the best option for today.
- Part 4-15「你要回复的消息比我多吗？」：❌ Do you have more messages than me to respond to ? → ✅ Do you have more messages to respond to than I do?

**规则**：普通名词不大写；环境 ≠ 服务器；`best option for today`；比较从句里把修饰短语放在名词后。
