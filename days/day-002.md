# Day 002 — 一般现在时

> 语法专题：`grammar/02-present-simple.md`

## Part 1 复习抽查（5 min）

1. 写出 be 动词在 she / we 后的肯定、否定形式。

答案：

```
she isn't
we arn't
```

正确答案：

```
She is / she's · She is not / she isn't / she's not
We are / we're · We are not / we aren't / we're not
```

解析：题目要求写出肯定、否定两种形式；aren't 拼写是 aren't，不是 arn't。

2. 「他在会议室」用英文怎么说？

答案：

```
He is in the meeting room.
```

3. 改错：I am engineer and I am very busy today.

答案：

```
I am an engineer and I am busy today.
```

## Part 2 语法复盘（10 min）

阅读 `grammar/02-present-simple.md`，然后完成下面练习。

### 今日要点

1. **一般现在时**：描述习惯、日常规律、固定安排——主语 + 动词原形（第三人称单数加 -s/-es）。
2. **第三人称单数**：he / she / it 及单数名词，动词要变形（works, checks, goes, studies）。
3. **频率副词位置**：实义动词前（I **usually** work）；be 动词后（She **is** often busy）。
4. **否定**：don't / doesn't + 动词原形——She **doesn't** work on weekends.
5. **疑问**：Do / Does 提前，动词用原形——**Does** he check email every morning?

### 练习

1. 填空：She \_\_\_ (check) emails every morning.

答案：

```
usually
```

正确答案：

```
checks
```

解析：括号里是动词 check，第三人称单数加 -s；usually 是频率副词，不能填在这里。

2. 改错：He work from home. I usually am busy in the afternoon.

答案：

```
He works from home. I am usually busy in the afternoon.
```

3. 翻译：你经常开会吗？

答案：

```
Do you often have meetings?
```

4. 翻译：他不在周末工作。

答案：

```
He doesn't work on weekends.
```

5. 用频率副词造句（已给词，排列成句）：I / sometimes / read / technical docs / on the subway.

答案：

```
I sometimes read technical docs on the subway.
```

## Part 4 回译练习（20 min）

把下面 **18 句中文** 译成英文。注意第三人称单数、频率副词位置，以及 don't/doesn't 的用法。

1. 我每天早上九点开始工作。

答案：

```
I start working at 9 am. every morning.
```

正确答案：

```
I start work at 9 a.m. every morning.
```

解析：every morning 前不用句号断开；「开始工作」习惯说 start work；时间写法常用 9 a.m.

2. 她通常在家远程办公。

答案：

```
She is usually remote working at home.
```

正确答案：

```
She usually works from home.
```

解析：描述日常习惯用一般现在时 works from home；不说 remote working，频率副词 usually 放在实义动词前。

3. 他每天检查邮件。

答案：

```
He check emails every day.
```

正确答案：

```
He checks emails every day.
```

解析：he / she / it 后动词要加 -s，He checks 不是 He check。

4. 我们每周一开站会。

答案：

```
We have a standup every Monday.
```

5. 他很少加班。

答案：

```
He rarely works overtime.
```

6. 你经常喝咖啡吗？

答案：

```
Do you often drink coffee?
```

7. 产品经理每周写周报。

答案：

```
The product manager writes weekly report every week.
```

正确答案：

```
The product manager writes a weekly report every week.
```

解析：report 是可数名词，第一次提到要加 a；weekly report 和 every week 连用略重复，口语可只说 writes a weekly report。

8. 我一般午饭前完成代码审查。

答案：

```
I often finish code review before lunch.
```

正确答案：

```
I usually finish code reviews before lunch.
```

解析：「一般」对应 usually 而非 often；习惯性的审查用复数 code reviews 更自然。

9. 新同事还不太熟悉这个流程。

答案：

```
The new colleague still doesn't know this process well.
```

正确答案：

```
The new colleague isn't familiar with this process yet.
```

解析：「熟悉流程」固定说 be familiar with，「还不太」用 yet 比 still doesn't know 更贴切。

10. 后端团队每天部署到测试环境。

答案：

```
The backend team deploys to test environment every day.
```

正确答案：

```
The backend team deploys to the test environment every day.
```

解析：特指的测试环境前加 the，the test environment 是固定说法。

11. 她不在晚上回复消息。

答案：

```
She doesn't reply message at night.
```

正确答案：

```
She doesn't reply to messages at night.
```

解析：reply 是不及物动词，要说 reply to messages；message 用复数表泛指。

12. 你们团队多久发布一次？

答案：

```
How often does your team publish?
```

13. 他总是在合并前跑测试。

答案：

```
He always runs tests before merging.
```

14. 我有时在地铁上读技术文档。

答案：

```
I sometimes read technical docs on the subway.
```

15. 设计同事通常下午才在线。

答案：

```
The design colleague is usually online afternoon.
```

正确答案：

```
The designer is usually online in the afternoon.
```

解析：be 动词后频率副词 usually 位置正确，但「下午」要说 in the afternoon；design colleague 可简化为 designer。

16. 我们不会在工作日晚上开会。

答案：

```
We don't have meetings in workday night.
```

正确答案：

```
We don't have meetings on weeknight evenings.
```

解析：「工作日的晚上」不说 workday night，常用 on weeknight evenings 或 on weekday evenings。

17. 每个 sprint 我们计划下一周的任务。

答案：

```
We plan next week task every sprint.
```

正确答案：

```
We plan next week's tasks every sprint.
```

解析：「下一周的任务」用所有格 next week's tasks；task 用复数表多项任务。

18. 他每天锻炼，所以状态很好。

答案：

```
He exercises everyday, so He has good status.
```

正确答案：

```
He exercises every day, so he is in good shape.
```

解析：表频率的「每天」写 every day（两个词）；句中 he 不大写；「状态很好」说 in good shape，不说 good status。

## 错题回顾

### be 动词形式不完整

- Part 1-1「she / we 后的肯定、否定形式」：❌ she isn't / we arn't → ✅ She is · She isn't / We are · We aren't

**规则**：题目要肯定、否定都写；aren't 拼写是 aren't，不是 arn't。

### 第三人称单数

- Part 2-1「She ___ (check) emails」：❌ usually → ✅ checks
- Part 4-3「他每天检查邮件」：❌ He check emails → ✅ He checks emails

**规则**：he / she / it 及单数主语后，动词加 -s/-es；写完后专门扫一遍第三人称句。

### 一般现在时 / 时态误用

- Part 4-2「她通常在家远程办公」：❌ She is usually remote working at home → ✅ She usually works from home

**规则**：描述日常习惯用一般现在时；频率副词 usually 放在实义动词前，不用 be + doing。

### 冠词缺失

- Part 4-7「产品经理每周写周报」：❌ writes weekly report → ✅ writes a weekly report
- Part 4-10「部署到测试环境」：❌ to test environment → ✅ to the test environment

**规则**：可数单数名词首次提到加 a/an；特指环境/场所加 the。

### 介词与固定搭配

- Part 4-9「还不太熟悉这个流程」：❌ still doesn't know…well → ✅ isn't familiar with…yet
- Part 4-11「不在晚上回复消息」：❌ reply message → ✅ reply to messages
- Part 4-15「通常下午才在线」：❌ online afternoon → ✅ online in the afternoon
- Part 4-16「工作日的晚上不开会」：❌ in workday night → ✅ on weeknight evenings

**规则**：记固定搭配——be familiar with、reply to、in the afternoon；「工作日晚上」说 weeknight/weekday evenings，不直译 workday night。

### 中式直译

- Part 4-18「状态很好」：❌ good status → ✅ in good shape

**规则**：「身体/状态好」说 in good shape 或 feel great，不说 good status。

### 细节

- Part 4-1「九点开始工作」：❌ at 9 am. every morning → ✅ at 9 a.m. every morning
- Part 4-8「一般午饭前」：❌ often finish code review → ✅ usually finish code reviews
- Part 4-17「下一周的任务」：❌ next week task → ✅ next week's tasks
- Part 4-18「每天锻炼」：❌ everyday → ✅ every day（表频率写两个词）

**规则**：「一般」用 usually；所有格加 's；表频率的 every day 是两个词，everyday 是形容词（everyday routine）。
