## Part 1 复习抽查

1. 选词填空（don't have to / shouldn't）：不必晚走：She **\_** stay late tonight.

答案：

```
shouldn't
```

正确答案：

```
doesn't have to
```

解析：「不必」是没有义务，用 `doesn't have to`；`shouldn't` 是「不该」，意思不同。

2. 改错（原意是「我今天必须提交这张工单」）：We must submit this ticket today.

答案：

```
I must submit this ticket today.
```

3. 翻译：你会回复这条消息吗？

答案：

```
Will you respond to this message?
```

## Part 2 语法复盘

阅读 `grammar/12-questions-negation.md`，然后完成下面练习。

### 今日要点

1. 先分清动词：`submit / confirm` 这类**动作动词**（也叫实义动词）表示具体动作，疑问/否定要加 `do / does / did`。
2. **情态动词**（can / will / should / must，表示能/会/应该/必须）和 **be**（is / are）自己就能提问和否定，不要再加 `do`。
3. **助动词**（do / is / can 等，用来帮忙提问或否定）要放到主语前面：Why didn't he...? 不是 Why he didn't...?
4. `Who` 表示「谁做了这件事」时，它已经是主语，通常不再加 `do`：Who missed the standup?
5. `yet` 多用于否定和疑问；`anyone / anything` 也常见于否定和疑问。

### 练习

1. 改错：You submitted the ticket yesterday?

答案：

```
Did you submit the ticket yesterday?
```

2. 填空：He **\_ (not confirm)** the plan yet.

答案：

```
He didn't confirm the plan yet.
```

3. 改错：Why he didn't follow the process?

答案：

```
Why didn't he follow the process?
```

4. 填空：Who **\_ (miss)** the standup yesterday?

答案：

```
Who miss the standup yesterday?
```

正确答案：

```
Who missed the standup yesterday?
```

解析：`Who` 作主语时不再加 `do`，但动词仍要按时间变化；有 `yesterday` 用过去式 `missed`。

5. 改错（原意是「我们必须升级预发服务器吗？」）：Do we have to update the staging server today?

答案：

```
Do we have to upgrade the staging server?
```

正确答案：

```
Do we have to upgrade the staging server today?
```

解析：`update` 改成 `upgrade` 是对的，但原句里的 `today` 不能漏掉。

## Part 4 回译练习

把下面 **18 句中文** 译成英文。注意：`submit / confirm` 这类动作动词，疑问和否定要加 `do / does / did`，并把 do / is / can 等放到主语前面；be 和 can / will / should / must 直接提前，不要再加 `do`。

1. 你今天提交这张工单了吗？

答案：

```
Did you submit this ticket today?
```

2. 她通常更新文档吗？

答案：

```
Does she usually update the document?
```

3. 他们遵循这个流程吗？

答案：

```
Did they follow the process?
```

正确答案：

```
Do they follow the process?
```

解析：中文没有过去时间，问的是习惯或规则，用 `Do they`；`Did they` 变成「他们当时遵循了吗」。

4. 你再核对过这些数据了吗？

答案：

```
Did you already double-check these data?
```

正确答案：

```
Did you double-check the data?
```

解析：本课里 `data` 当不可数，用 `the data` / `this data`，不要 `these data`；`already` 可加，但不是必须。

5. 他还没有确认这个计划。

答案：

```
He didn't confirm this plan.
```

正确答案：

```
He didn't confirm this plan yet.
```

解析：「还没有」在否定句里要把 `yet` 译出来：`didn't ... yet`。

6. 她已经提到这个延迟了吗？

答案：

```
Did she already mention the delay?
```

7. 为什么没有人回复这条消息？

答案：

```
Why didn't anyone respond to this message?
```

8. 你还需要澄清别的事情吗？

答案：

```
Do you need to clarify anything else?
```

9. 这个延迟一点也不是问题。

答案：

```
This delay isn't an issue at all.
```

10. 谁错过了站会？

答案：

```
Who missed the standup?
```

11. 你什么时候会回复我？

答案：

```
When do you respond to me?
```

正确答案：

```
When will you get back to me?
```

解析：「会」用 `will`，不要用习惯性的 `do`；「回复我」这里用当天搭配 `get back to me`。

12. 昨天她没有准备报告。

答案：

```
She didn't prepare the report yesterday.
```

13. 他们现在在调试吗？

答案：

```
Are they debugging now?
```

14. 我今天必须提交这张工单吗？

答案：

```
Do I have to submit this ticket today?
```

15. 我们今天必须升级预发服务器吗？

答案：

```
Do we have to upgrade the staging server today?
```

16. 她今晚不必晚走。

答案：

```
She doesn't have to stay late tonight.
```

17. 你为什么没有回复这条消息？

答案：

```
Why didn't you respond to the message?
```

正确答案：

```
Why didn't you respond to this message?
```

解析：助动词提前和 `respond to` 都对；「这条」要译成 `this`。

18. 他现在没有在准备报告吗？

答案：

```
Doesn't he preparing the report now?
```

正确答案：

```
Isn't he preparing the report now?
```

解析：现在进行时的疑问用 be 提前：`Isn't he preparing`；不要把 `do` 和 `-ing` 叠在一起。

## 错题回顾

### don't have to ≠ shouldn't

标签：`表达-中式直译`

- Part 1-1「不必晚走：She \_ stay late tonight.」：❌ shouldn't → ✅ doesn't have to

**规则**：`don't / doesn't have to` = 不必做；`shouldn't` = 不该做。

### do / did 要看有没有过去时间

标签：`时态-过去式`、`时态-现在时`

- Part 2-4「Who \_ (miss) the standup yesterday?」：❌ Who miss the standup yesterday? → ✅ Who missed the standup yesterday?
- Part 4-3「他们遵循这个流程吗？」：❌ Did they follow the process? → ✅ Do they follow the process?

**规则**：`Who` 作主语时不再加 `do`，但有 `yesterday` 仍用过去式 `missed`；没有过去时间就用 `Do / Does`，不要用 `Did`。

### 中文里的 yet / today / this / 会 不要漏

标签：`信息-漏译`

- Part 2-5「我们必须升级预发服务器吗？」：❌ Do we have to upgrade the staging server? → ✅ Do we have to upgrade the staging server today?
- Part 4-5「他还没有确认这个计划。」：❌ He didn't confirm this plan. → ✅ He didn't confirm this plan yet.
- Part 4-11「你什么时候会回复我？」：❌ When do you respond to me? → ✅ When will you get back to me?
- Part 4-17「你为什么没有回复这条消息？」：❌ Why didn't you respond to the message? → ✅ Why didn't you respond to this message?

**规则**：先核对时间词、限定词和当天搭配；「还没有」加 `yet`，「会」用 `will`，「回复我」用 `get back to me`。

### data 不可数

标签：`表达-中式直译`

- Part 4-4「你再核对过这些数据了吗？」：❌ Did you already double-check these data? → ✅ Did you double-check the data?

**规则**：`data` 在本课当不可数，用 `the data` / `this data`，不要 `these data`。

### 进行时疑问用 be

标签：`时态-进行时`

- Part 4-18「他现在没有在准备报告吗？」：❌ Doesn't he preparing the report now? → ✅ Isn't he preparing the report now?

**规则**：`now` 且表示正在发生时，疑问句把 `is / are` 提前，不要写成 `doesn't + -ing`。
