## Part 2 语法复盘

阅读 `grammar/05-past-simple.md`，然后完成下面练习。

### 今日要点

1. **一般过去时**：表示过去明确时间发生的动作或状态。
2. **规则动词**：多数动词加 **-ed**，如 checked、reviewed、deployed。
3. **不规则动词**：需要单独记，如 went、found、wrote、had、made。
4. **否定和疑问**：用 didn't / Did 后，动词回到原形。
5. **纠偏**：有 yesterday、last night、last week 等过去时间时，动词要用过去式。

### 练习

1. 填空：I \_\_\_ (check) the logs yesterday. She \_\_\_ (review) the PR last night.

答案：

```
I checked the logs yesterday. She reviewed the PR last night.
```

2. 改错：He didn't fixed the bug yesterday.

答案：

```
He didn't fix the bug yesterday.
```

3. 填空：We \_\_\_ (find) a config error in the test environment this morning.

答案：

```
found
```

4. 翻译：你昨天打开工单了吗？

答案：

```
Did you open the ticket yesterday?
```

正确答案：

```
Did you open a ticket yesterday?
```

解析：这里是「开一张工单」，第一次提到用 a ticket；the ticket 更像「打开那张已有工单」。

5. 翻译：他们上周没有部署这个服务。

答案：

```
They didn't deploy this service last week.
```

## Part 4 回译练习

1. 我昨天检查了日志。

答案：

```
I checked the logs yesterday.
```

2. 她昨晚审查了这个 PR。

答案：

```
She reviewed this PR last night.
```

答案：

```

答案：

```

```

答案：

```

```

正确答案：

解析：工作里的「问题/事项」通常用 issue；question 更偏「疑问」。

答案：

```

## 错题回顾

### 冠词与指代

- Part 2-4「你昨天打开工单了吗？」：❌ Did you open the ticket yesterday? → ✅ Did you open a ticket yesterday?

**规则**：第一次提到一张工单用 a ticket；the ticket 表示双方已知的那张工单。

### 工作场景词义

- Part 4-6「他们上周讨论了这个问题」：❌ They discussed this question last week. → ✅ They discussed this issue last week.

**规则**：职场里的「问题/事项」多用 issue；question 主要指「疑问」。

### 会议搭配

- Part 4-9「他午饭后参加了会议」：❌ He had a meeting after lunch. → ✅ He joined the meeting after lunch.

**规则**：参加会议用 join/attend the meeting；have a meeting 表示「开会/有一场会」。
