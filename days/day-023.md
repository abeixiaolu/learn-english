## Part 2 语法复盘

### 1. 先认清原因和结果

原因是“为什么”，结果是“因此怎么样”。例如“会议室很吵，因此我们不能在里面开会”：很吵是原因，不能开会是结果。连接前先把两部分分清。

### 2. because 后接完整的原因句

结构：结果句 + because + 原因句。

I am staying late because this release is important.（我会晚走，因为这次发布很重要。）

because 后通常要有主语和谓语，也就是写出“谁做什么”或“什么是什么状态”。前后说同一个人，也不能随意省掉后半句的主语。这里紧密相连的 because 原因句前通常不加逗号。

### 3. so 后接完整的结果句

结构：原因句 + , so + 结果句。

The hallway is noisy, so we are going to join the call in the meeting room.（走廊很吵，所以我们打算在会议室加入通话。）

表达同一组因果关系，选 because 或 so 其中一个，不同时使用两者重复连接。换连接词时，先判断哪一部分应放前面。

### 4. 连接后仍要检查每个简单句

连接词不会代替 be，也不会改变动作动词原本的形式。形容词表达状态时需要 be；一般现在时的第三人称单数、过去式、情态动词后接原形等规则仍适用。

写完逐个分句核对人物、日期、钟点和地点。具体某一天“不必做”要保留日期；阅读文字报告用 read。不要为了连接句子而省掉题目中的关键信息。

### 练习

按要求作答；合句时保留全部信息，不增加内容。

1. 用 because 连接，先说结果：We cannot join the call today. We have to review these files today.

答案：

```
We cannot join the call today because  we have to review these files today.
```

2. 用 so 连接，先说原因：This ticket is urgent. She must respond to it this morning.

答案：

```
This ticket is urgent, so she must respond to it this morning.
```

3. 填入括号中词的正确形式：He **_ (check) the calendar every morning because he _** (have) meetings every day.

答案：

```
checks, has
```

4. 用 so 连接，先说原因：We found an issue yesterday. We are going to update that document tomorrow.

答案：

```
We found an issue yesterday, so we are going to update that document tomorrow.
```

## Part 4 回译练习

按指定连接词作答。前 13 题练因果表达，后 5 题结合旧错点；每个分句都保留原有信息。

1. 这台服务器离线了，所以我们现在不能访问它。（用 so）

答案：

```
This server is offline, so we cannot access it now.
```

2. 我现在不能加入通话，因为我的笔记本电脑离线了。（用 because）

答案：

```
I cannot join the call now because my laptop is offline.
```

3. 那台服务器现在在线，所以你现在可以访问它。（用 so）

答案：

```
That server is online now, so you can access it.
```

表达说明（不计错）：前半句的 now 已明确当前语境，后半句 can access it 自然承接，不必重复 now。

4. 我们可以使用这台打印机，因为它现在在线。（用 because）

答案：

```
We can use this printer because it is online.
```

表达说明（不计错）：本句 is online 在当前使用打印机的语境下可表达“现在在线”，接受；也可写 is online now 让时间更明确。

5. 这个会议室是空的，所以我们可以在这里开会。（用 so）

答案：

```
This meeting room is empty, so we can have meetings here.
```

6. 我们不能在那个会议室开会，因为它已经满员了。（用 because）

答案：

```
We cannot have meetings in that meeting room because it is full.
```

表达说明（不计错）：is full 已表达当前满员状态，不必为中文“已经”机械补 already；本题 have meetings 可接受，指眼前这一次会议时 have a meeting 更自然。

7. 这份报告准备好了，所以我现在会把它发给你。（用 so；当场决定）

答案：

```
This  report is ready, so I will send it to you now.
```

8. 我们今天不能部署，因为这些文件还没有准备好。（用 because；“还没有准备好”用 not ready yet）

答案：

```
We cannot deploy today because  these files are not ready yet.
```

9. 这个密码不对，所以我现在不能访问那台服务器。（用 so）

答案：

```
This password is not correct, so I cannot access that server now.
```

10. 你应该再核对一遍这些数据，因为这个结果是错的。（用 because）

答案：

```
You should double check these data because this result is wrong.
```

书写与表达提醒（不计错）：double-check 本课统一加连字符；these data 是可接受的正式复数用法。

11. 连接很慢，所以我现在不能共享屏幕。（用 so）

答案：

```
The connection is slow, so I cannot share my screen now.
```

12. 我们必须今天上午回复这条消息，因为它很紧急。（用 because）

答案：

```
We must respond to this message this morning because it is urgent.
```

13. 这台打印机坏了，所以我们今天不必使用它。（用 so）

答案：

```
This printer is broken, so we don't have to use it.
```

正确答案：

```
This printer is broken, so we don't have to use it today.
```

解析：后半句漏了“今天”，需要补 today，才能明确只是今天不必使用；don't have to 的“不必”含义和 so 的因果方向均正确。

14. 食堂很吵，所以她现在在大厅里等我们。（用 so；后半句用现在进行时）

答案：

```
The cafeteria is noisy, so she is waiting for us in the lobby now.
```

15. 我找不到那本纸质笔记本，因为它在柜子里。（用 because；“找不到”用 cannot find）

答案：

```
I cannot find that notebook because it is in the cabinet.
```

16. 她现在没空，所以我稍后会问她。（用 so；当场决定）

答案：

```
She is not available now, so I will ask her later.
```

17. 他现在在阳台上，因为那里很安静。（用 because）

答案：

```
He is on the balcony now because it is quiet.
```

18. 我今天上午十点必须在入口处等他，所以我现在不能加入通话。（用 so）

答案：

```
I must wait for him at the entrance at 10 o'clock morning today, so I cannot join the call now.
```

正确答案：

```
I must wait for him at the entrance at 10 a.m. today, so I cannot join the call now.
```

解析：上午十点用 at 10 a.m.，也可用 at 10 o'clock this morning；不能把 morning 直接接在 o'clock 后。你已保留今天、上午十点、入口、他和现在，问题是时间表达结构，不是信息漏译。

## 错题回顾

### 阳台词汇与介词

标签：`搭配-介词`、`信息-漏译`

- Part 1-3：❌ in the 阳台 → ✅ on the balcony。

**规则**：阳台写作 balcony，表达在阳台上用 on the balcony；中文占位尚未完成英文翻译。


### 具体日期不能漏

标签：`信息-漏译`

- Part 4-13：❌ we don't have to use it → ✅ we don't have to use it today。

**规则**：题目把“不必”限定在今天时，要明确保留 today，不能变成没有日期限制的不必。

### 钟点与上午的表达

标签：`搭配-介词`

- Part 4-18：❌ at 10 o'clock morning today → ✅ at 10 a.m. today；也可写 at 10 o'clock this morning。

**规则**：钟点可用 at + 数字 + a.m. / p.m.；使用 o'clock 时，上午可用 in the morning 或 this morning，不能直接加 morning。
