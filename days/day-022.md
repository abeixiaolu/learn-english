## Part 2 语法复盘

**仅在 Part 1 批改通过后阅读。** 本次只学把两个简单句连起来，不增加新时态。so 在过去练习中出现过，今天正式整理它与 because 的关系。

### 1. 先分清原因和结果

原因回答“为什么”，结果回答“因此发生了什么”。例如“我没空，因此不能加入通话”：没空是原因，不能加入通话是结果。

### 2. because 后面说原因

基本结构：结果句 + because + 原因句。这里的“句”是包含主语和谓语的部分；谓语可以是 be，也可以是表示动作的动词。

例句：I can't join the call because I am busy.（我不能加入通话，因为我很忙。）

because 后面要把“谁怎么样”说完整。主语即使与前半句相同，通常也要写出来。今天先只练这种顺序；不扩展 because of。

### 3. so 后面说结果

基本结构：原因句 + , so + 结果句。

例句：The printer isn't working, so we can't print this document.（打印机不能工作，所以我们无法打印这份文档。）这里 print 表示“打印”，只用于讲解，不要求背诵。

同一组原因与结果，用 because 连接时先说结果，用 so 连接时先说原因。今天每次只选一个连接词，不把 because 和 so 同时用来连接同一对分句。

### 4. 每个分句都检查原来的规则

连接词不会代替 be 或助动词，也不会改变三单、过去式等规则。先分别写对两个简单句，再连接。不要只检查连接词，还要核对每个分句的人物、否定含义、日期、时段和钟点。

### 练习

用指定连接词合成一个句子，保留原有信息；不需要增加内容。

1. 用 because 连接，先说结果：We must review these files. This release is important.

答案：

```
We must review these files, because this release is important.
```

2. 用 so 连接，先说原因：She is not available today. She cannot join the meeting today.

答案：

```
She is not available today, so she cannot join the meeting today.
```

3. 用 because 连接，先说结果：He checks the schedule every morning. He has meetings every day.

答案：

```
He checks the schedule every morning, because he has meetings every day.
```

4. 用 so 连接，先说原因：We found an issue yesterday. We are going to update this document tomorrow.

答案：

```
We found an issue yesterday, so we are going to update this document tomorrow.
```

## 错题回顾

### 时间信息完整保留

标签：`信息-漏译`

- Part 1-1：原答案没有表达“今天”；需补 today。

**规则**：每个分句分别核对哪天、哪个时段、几点，不把当天的“不必”写成无时间限制的陈述。

### 大厅词义与阅读搭配

标签：`语义-词义`

- Part 1-1：❌ in the hobby → ✅ in the lobby。
- Part 1-3：❌ watching that report → ✅ reading that report。

**规则**：lobby 是大厅，hobby 是爱好；阅读文字报告、文档用 read。当前错误属于词义选择，不把正确的进行时和地点介词算错。

### 人物代词要与题目一致

标签：`信息-漏译`

- Part 1 补充复查-3：❌ wait for her → ✅ wait for him；原题为“等他”。

**规则**：for 后用宾格；他用 him，她用 her。这里错在人物选择，不是宾格结构。

### 今天与明天不能互换

标签：`信息-时间`

- Part 1 最后一题复查：❌ at 4 p.m. tomorrow → ✅ at 4 p.m. today。

**规则**：today 是今天，tomorrow 是明天；钟点正确也不能替代日期核对。
