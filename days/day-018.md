## Part 2 语法复盘

### 1. 先判断：不做、不必，还是禁止

“不做”描述动作不发生；“不必”表示没有义务，做了也可以；“禁止”表示不允许做。这三个意思不能互换。

| 想表达的意思 | I / you / we / they      | he / she / it              |
| ------------ | ------------------------ | -------------------------- |
| 不做某事     | don't + 动词原形         | doesn't + 动词原形         |
| 不必做某事   | don't have to + 动词原形 | doesn't have to + 动词原形 |
| 禁止做某事   | mustn't + 动词原形       | mustn't + 动词原形         |

例句：`They don't write unit tests.` 表示他们不写单元测试；`They don't have to write unit tests.` 表示他们不必写；`They mustn't write unit tests.` 表示他们被禁止写。

### 2. 第三人称：does 已经承担了变化

“第三人称单数”指 he、she、it，或一个同事、一个计划等单个对象。一般现在时肯定句中，动作动词通常加 -s / -es；否定和提问用了 does / doesn't，后面的动作动词用原形。

例句：`The engineer prepares the report.` → `The engineer doesn't prepare the report.` → `Does the engineer prepare the report?`

has to 也遵守这个规则：否定时用 doesn't have to，提问时用 Does + 主语 + have to。usually 一般放在动作动词前；否定句中通常放在 doesn't 后。

### 3. “必须吗”要把疑问结构写出来

must 是情态动词，也就是帮助表达必须、建议、能力等意思的词，后面接动词原形。用 must 提问时，把它移到主语前；用 have to 提问时，用 do / does 帮忙。

- Must + 主语 + 动词原形 …?
- Do / Does + 主语 + have to + 动词原形 …?

例句：`Must they wait for feedback?` 和 `Do they have to wait for feedback?` 都可以问“他们必须等反馈吗？”。must 不随 he / she / it 变形。

### 4. 流程、时间与 before 一起检查

表达“按流程要求做某事”，可以用 **as part of the process**，意思是“作为流程的一部分”；这个搭配此前批改中已经出现过。例句：`They have to confirm the deadline as part of the process.` 不要把命令别人遵循流程的祈使句直接当成修饰语。

before 后可接名词、动作的 -ing 形式，或有自己主语和动词的完整句子。例句：`We discuss the issue before opening a ticket.` 指双方知道的某次发布时，用 the release 能明确这一次发布。

写完依次检查：时间有没有漏、主语是否需要 does、原句是不是提问、表达的是“不做”还是“不必”。有明确过去时间时，didn't 后仍接原形。

## Part 4 回译练习

1. 她通常不处理这张工单。

答案：

```
She doesn't usually handle this ticket.
```

2. 她今天不必处理这张工单。

答案：

```
She doesn't have to handle this ticket.
```

正确答案：

```
She doesn't have to handle this ticket today.
```

解析：doesn't have to 正确表达了“不必”，但漏译了“今天”，需要补上 today。

3. 她今天必须处理这张工单吗？（用 have to 提问）

答案：

```
Does she have to handle this ticket today?
```

4. 你禁止访问这台服务器。

答案：

```
You mustn't access this server.
```

5. 我们今天不升级这台服务器。

答案：

```
We don't upgrade this server today.
```

6. 我们今天不必升级这台服务器。

答案：

```
We don't have to upgrade this server today.
```

7. 我们今天必须升级这台服务器吗？（用 must 提问）

答案：

```
Must we upgrade this server today?
```

8. 我的同事通常不在周末加班。（用 on weekends）

答案：

```
My colleague doesn't usually work overtime on weekends.
```

9. 按照流程，他必须审查这些文件。（用 as part of the process）

答案：

```
He must review these files as part of the process.
```

10. 按照流程，她必须申请批准吗？（用 have to 提问；用 as part of the process）

答案：

```
Does she have to ask for approval as part of the process?
```

11. 他们今天需要一些反馈，但不需要更多数据。

答案：

```
They need some feedback, but they don't need much data.
```

正确答案：

```
They need some feedback today, but they don't need more data.
```

解析：漏译了“今天”；much data 表示“很多数据”，more data 才表示“更多数据”，题目是不需要更多，而非不需要很多。

12. 他昨天发现了一个问题，但没有开工单。

答案：

```
He found a issue yesterday, but he didn't open a ticket.
```

正确答案：

```
He found an issue yesterday, but he didn't open a ticket.
```

解析：issue 以元音音素 /ɪ/ 开头，前面用 an；found、didn't open 和 yesterday 都正确。

13. 发送这份报告前，你应该再核对一遍这些数据。（before 后接发送动作）

答案：

```
You should double check these data before sending this report.
```

书写提醒（不计错）：before sending 正确；these data 是可接受的正式复数用法；“再核对”统一写作 double-check。

14. 这次发布前，她不必更新这个计划。（用名词表达这次发布）

答案：

```
She doesn't have to update this plan before the release.
```

15. 部署前，我必须检查这个文件吗？（用 must 提问；before 后接部署动作）

答案：

```
Must I check this file before deploying?
```

16. 她现在不是在调试吗？（用不缩写的否定疑问句）

答案：

```
Is she not debugging now?
```

17. 我们今天没有很多请求，但有很多时间。

答案：

```
We don't have many requests today, but we have much time.
```

表达建议（不计错）：肯定句中的 much time 语法成立，日常表达更自然的是 a lot of time：We don't have many requests today, but we have a lot of time。

18. 他通常每天审查文档，但他今天不必审查这些文件。

答案：

```
He usually reviews documents every day, but he doesn't have to review these files today.
```

## 错题回顾

### 时间信息不要漏

标签：`信息-漏译`

- Part 4-2「她今天不必处理这张工单。」：❌ She doesn't have to handle this ticket. → ✅ She doesn't have to handle this ticket today.
- Part 4-11「他们今天需要一些反馈，但不需要更多数据。」：❌ They need some feedback, but they don't need much data. → ✅ They need some feedback today, but they don't need more data.

**规则**：写完逐项核对“谁、什么时候、做什么”；语法正确也不能省掉题干明确给出的时间。

### 很多与更多要分清

标签：`语义-数量`

- Part 4-11「但不需要更多数据」：❌ but they don't need much data → ✅ but they don't need more data

**规则**：much 表示“很多”，more 表示“更多”；don't need more data 是“不需要更多数据”，不等于 don't need much data（不需要很多数据）。

### a / an 按发音选择

标签：`冠词-a-an`

- Part 4-12「他昨天发现了一个问题，但没有开工单。」：❌ He found a issue yesterday, but he didn't open a ticket. → ✅ He found an issue yesterday, but he didn't open a ticket.

**规则**：单数可数名词前需要限定词；用 a 还是 an 看后面紧邻词的开头发音，issue 以元音音素开头，用 an。
