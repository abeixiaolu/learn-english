## Part 2 语法复盘

### 01 — be：身份、状态、地点

「谁」是主语，如 I、she；身份、状态或地点放在 be 后。I 配 am；he / she / it 配 is；you / we / they 配 are。否定在 be 后加 not；提问把 be 放到主语前。

例句：`The report is ready.`（报告准备好了。）中文的「很」不必机械加 very；确实强调程度时可以加。

### 02 — 一般现在时：日常动作

表示做什么的词叫动作动词，如 review、update。说习惯或一般事实时，I / you / we / they 后用原形；he / she / it 或单个人、物后通常加 -s / -es。辅音字母加 y 结尾通常变 y 为 i 再加 -es。

提问和否定用 do / does 帮忙，这类帮忙的词叫助动词。结构是 **Do / Does + 谁 + 动词原形？** 或 **谁 + don't / doesn't + 动词原形**。用了 does，后面就恢复原形。

usually 等频率词一般放在动作动词前、be 后；否定句可放在 don't / doesn't 后。例句：`She usually checks files.`（她通常检查文件。）

### 03 — 冠词：一个，还是已知的那个

名词是人、东西等的名称，如 colleague、ticket。能一件件数的名词叫可数名词，单个通常要有 a / an / the / my / this 等限定。

首次引入不特指的一个常用 a / an；双方知道是哪一个，或再次提到同一个，用 the。a / an 看紧接着的发音：辅音音用 a，元音音用 an。例：`a user`、`an option`。

已有 my / this 就不叠加冠词；复数泛指、不可数泛指和许多专有名词不加冠词。

### 04 — there is / are：某处有东西

**There is / are + 东西 + 地点** 表示存在；have / has 表示某人拥有。单个或不可数用 is，复数用 are。否定在 is / are 后加 not；提问将 is / are 放到 there 前。

例句：`There are two laptops here.`（这里有两台笔记本电脑。）列举多个东西时通常按紧接着的第一个名词选 is / are。

### 05 — 一般过去时：明确的过去

yesterday、last night、last week 等提示已发生的过去动作。肯定句里动词用过去式：规则动词通常加 -ed；不规则变化如 find → found、write → wrote、have → had、make → made、send → sent，要单独记。

否定用 **didn't + 原形**；提问用 **Did + 谁 + 原形？**。过去状态用 was / were：am / is 变 was，are 变 were；它们自己加 not 或提前，不用 did。

例句：`They discussed the plan last night.`（他们昨晚讨论了计划。）不能只加 yesterday 而让动词仍保持现在时。

### 06 — can / can't：能力与请求

can 表示能、会，也用于请求或征求许可；后面用动词原形，不随人称变化。否定用 can't / cannot；提问把 can 提前。

例句：`Can I share my screen?`（我可以共享屏幕吗？）

### 07 — 现在进行时：正在做

正在发生的动作用 **谁 + am / is / are + 动词 -ing**。否定在 be 后加 not；提问把 be 提前，不额外加 do。

-ing 通常直接加；不发音 e 结尾去 e 再加，如 write → writing；run → running、debug → debugging 等需要双写。

例句：`We are reviewing the plan now.`（我们现在正在审查计划。）习惯用一般现在时；now 并不让所有动词都变进行时。need、know、like 等表示需要、知道、喜好的状态，通常不用进行时。have 表拥有时也是状态，表示开会等动作时可以用进行时。

### 08 — 数量：可数与不可数

可数名词可逐个数，如 file、request；不可数通常按整体或份量看，如 feedback、information、time，不能直接加 a 或复数 -s。data 在本课程的日常职场场景按不可数使用；其他语境也有复数用法。

| 意思       | 可数复数 | 不可数   |
| ---------- | -------- | -------- |
| 很多       | many     | much     |
| 一些、少量 | a few    | a little |
| 更少       | fewer    | less     |

some 常见于肯定句；any 常见于否定和疑问。请求或主动提供时疑问句也可以用 some。例：`a few resources`、`a little coffee`。肯定句说「很多」时 a lot of 也很常用。

### 09 — 比较与最高级

比较级表示「比另一个更……」：**A + be + 比较级 + than + B**。短词常加 -er；较长词常用 more；easy 变 easier。good 的比较级是 better，不再叠加 more。

最高级表示某个范围里「最……」：通常 **the + 最高级**，如 best、fastest、most reliable。

例句：`This laptop is cheaper than that one.`（这台电脑比那台便宜。）

### 10 — will / be going to：未来

will 后用原形，常表达临时决定、承诺或预测；否定用 won't，提问把 will 提前。

be going to 后也用原形，常表达已安排的计划或根据眼前迹象作判断；be 随主语变化，否定在 be 后加 not，提问把 be 提前。

例句：`I will review the document later.`（我稍后会审查文档。）`They are going to migrate the data next week.`（他们打算下周迁移数据。）这些是常见倾向，实际用法有重叠，要结合上下文，不能只看到「会」就机械选一种。

### 11 — should / must / have to：建议与义务

can、will、should、must 这类词表示能、会、应该、必须，叫情态动词；后面用原形。should 是建议；must 常强调强烈必要或规定；have to 常表示外部安排造成的义务，两种「必须」有重叠。

| 表达                    | 意思           |
| ----------------------- | -------------- |
| shouldn't               | 不该做（建议） |
| mustn't                 | 禁止做         |
| don't / doesn't have to | 不必做         |

have to 要跟着主语变化：第三人称肯定句用 has to；提问和否定用 do / does + have to。should / must 自己提前或加 not。

例句：`We should review this option.`（我们应该审查这个选项。）

### 12 — 疑问与否定：先看是哪类动词

- be：自己提前或加 not。
- can / will / should / must：自己提前或加 not，后面接原形。
- 一般现在/过去的动作：用 do / does / did 帮忙，后面接原形。
- 现在进行时：提前的是 be，动作仍保留 -ing。

问为什么、什么时候：**Why / When + 帮忙提问的词 + 谁 + 其余内容？**。Who 问「谁做了」时，who 已是主语，通常不用另加 do，但动词仍要按时间变化。

yet 多放在否定或疑问句末；already 表「已经」；anyone / anything 常见于否定和疑问；else 表「其他」，at all 可加强否定。

例句：`When can they join the call?`（他们什么时候能加入通话？）

### 写完后的检查

先核对谁、动作、时间，再核对否定、数量、限定词和地点。respond to、wait for、get back to 等搭配里的介词要保留。两个完整句子可用句号分开，或用 and / but 连接，不只用逗号连接。

## Part 4 回译练习

18 题混合回译，覆盖全部已学单元。部分题目包含两句，用来同时检查句型切换；接受符合原意的多种正确译法。

1. 我今天有空，但她今天很忙。

答案：

```
I am available today, but she is busy today.
```

2. 他通常审查文档，但他现在正在开会。

答案：

```
He usually reviews the document, but he is having a meeting now.
```

3. 我们每周开会，但昨天没有开会。

答案：

```
We have meetings every weeks, but we didn't have meetings yesterday.
```

正确答案：

```
We have meetings every week, but we didn't have any meetings yesterday.
```

解析：every 后的时间单位用单数 week；原句的 didn't have meetings 也可以，本例用 any 使否定更自然。

4. 我发现了一个问题。这个问题在登录流程里。（明确是昨天发现的）

答案：

```
I found a issue. It was in the login process.
```

正确答案：

```
I found an issue yesterday. The issue is in the login flow.
```

解析：issue 开头是元音音，用 an；题目明确是昨天发现，要补 yesterday，login process 和用 It 指代也可接受，若叙述当时状态 was 也成立。

5. 会议室里有两位同事。

答案：

```
There are two colleagues in the meeting room.
```

6. 她昨晚写了一份报告。

答案：

```
She wrote a report last night.
```

7. 你昨天检查这些数据了吗？

答案：

```
Did you check this data yesterday?
```

8. 你能帮我处理这张工单吗？

答案：

```
Can you help me with handling this ticket?
```

9. 他现在没有在调试吗？

答案：

```
Is not he debugging now?
```

正确答案：

```
Isn't he debugging now?
```

解析：缩写形式是 Isn't he；不缩写时应是 Is he not，not 不放在 he 前。

10. 她现在需要一些反馈。

答案：

```
She need some feedback now.
```

正确答案：

```
She needs some feedback now.
```

解析：need 表需要，用一般现在时是对的；She 后的肯定句动词要加 -s。

11. 我们有一些文件，但没有任何权限。

答案：

```
We have a few files, but we don't have any permissions.
```

12. 我们今天请求更少，但没有很多时间。

答案：

```
We have less requests, but we have no more time.
```

正确答案：

```
We have fewer requests today, but we don't have much time.
```

解析：requests 可数复数，用 fewer；「没有很多时间」用 don't have much time，no more time 是「没有更多/不再有时间」，还要保留 today。

13. 我的笔记本电脑在我的桌上。它比你的电脑更快。

答案：

```
My laptop is on my desk. It is faster than your laptop.
```

14. 这是这三个选项中最好的一个。

答案：

```
This is the best one in the three options.
```

15. 好的，我稍后会回复你。（当场作出承诺）

答案：

```
Ok, i will respond to you later.
```

正确答案：

```
OK, I will respond to you later.
```

解析：will 和 respond to you 都正确；第一人称 I 必须大写，也可用 get back to you，不能因没用指定搭配判错。

16. 我们已经安排好了：下周升级预发服务器。

答案：

```
We are going to upgrade the staging server next week.
```

17. 你应该再核对一遍这些数据；她今天不必加班。

答案：

```
You should double check these data; She doesn't have to work overtime today.
```

18. 发布前，我必须申请批准吗？（流程规定）

答案：

```
Must i ask for approval before publish?
```

正确答案：

```
Do I have to ask for approval before the release?
```

解析：I 要大写；before 后不能直接放动词原形 publish，此处可用名词 the release；Must I ask ... 也正确，have to 更突出流程义务。

## 错题回顾

### 时间信息与原意要保留

标签：`信息-漏译`

- Part 1-2：❌ We have a meeting today. → ✅ We have meetings every day.
- Part 1-5：❌ He doesn't have to work overtime. → ✅ He doesn't have to stay late today.

**规则**：先圈出每天、今天、昨天等时间信息，翻译后逐个核对。

### 明确过去时间要变过去式

标签：`时态-过去式`

- Part 2-5：❌ writes → ✅ wrote

**规则**：肯定句有明确过去时间时用过去式；did / didn't 后才用原形。

### 时间、数量与流程表达

标签：`表达-中式直译`

- Part 2-11：❌ Follow the process, She must ask for approval. → ✅ She has to ask for approval as part of the process.
- Part 4-3：❌ We have meetings every weeks, but we didn't have meetings yesterday. → ✅ We have meetings every week, but we didn't have any meetings yesterday.
- Part 4-12：❌ We have less requests, but we have no more time. → ✅ We have fewer requests today, but we don't have much time.

**规则**：every 配单数时间单位；数量表达先判断可数性，再核对意思；不要把命令句当修饰语。

### 冠词按发音选择

标签：`冠词-a-an`

- Part 4-4：❌ I found a issue. It was in the login process. → ✅ I found an issue yesterday. The issue is in the login flow.

**规则**：元音音开头用 an，不只看字母；发现动作的时间也要保留。

### 否定疑问句的 not 位置

标签：`句式-疑问语序`

- Part 4-9：❌ Is not he debugging now? → ✅ Isn't he debugging now?

**规则**：be 否定疑问可缩写为 Isn't + 主语，或不缩写为 Is + 主语 + not。

### 第三人称肯定句加 -s

标签：`时态-三单`

- Part 4-10：❌ She need some feedback now. → ✅ She needs some feedback now.

**规则**：一般现在时肯定句里 he / she / it 后的动作动词通常加 -s。

### 第一人称 I 大写

标签：`拼写-专有名词`

- Part 4-15：❌ Ok, i will respond to you later. → ✅ OK, I will respond to you later.

**规则**：I 无论放在哪里都大写。

### before 后的词形

标签：`搭配-介词`

- Part 4-18：❌ Must i ask for approval before publish? → ✅ Do I have to ask for approval before the release?

**规则**：before 后可接名词或 -ing 形式，不直接接动词原形；must 提问与 have to 提问都可正确。

```
She prepares reports every day.
```

批改：✅ 正确。第三人称 prepares 和 every day 都正确。

2. 翻译：我们今天开会，但不是每天都开会。

答案：

```
We have meetings today, but we don't have meetings every day.
```

批改：✅ 正确。today 与 every day 区分正确，肯定和否定的结构都对。

3. 翻译：他昨天没有加班。

答案：

```
He didn't work overtime yesterday.
```

批改：✅ 正确。过去时否定用了 didn't + 原形，也保留了 yesterday。

4. 填空：They \_\_\_ (write) the document last week.

答案：

```
They wrote the document last week.
```

批改：✅ 正确。write 的过去式 wrote 正确，写完整句也接受。

5. 翻译：我昨晚发现了一个问题。（第一次提到）

答案：

```
I found an issue last night.
```

批改：✅ 正确。found、an issue 和 last night 都正确。

6. 翻译：她通常回复消息。

答案：

```
She usually respond to the message.
```

批改：❌ 需要修改。

正确答案：

```
She usually responds to messages.
```

解析：She 后的一般现在时肯定句，respond 要加 -s；泛指平常回复消息时用 messages，the message 则指某条已知消息。

7. 改错：Are not they preparing the report now?

答案：

```
Are they not preparing the report now?
```

批改：✅ 正确。不缩写时把 not 放在主语 they 后，正确。

8. 把句子改成不使用缩写的否定疑问句：She is working on this ticket now.

答案：

```
Is she not working on this ticket now?
```

批改：✅ 正确。Is she not ... 的语序正确，也保留了 working。

9. 翻译：我们今天没有很多反馈。

答案：

```
We have less feedback today.
```

批改：❌ 需要修改。

正确答案：

```
We don't have much feedback today.
```

解析：less feedback 表示「反馈更少」，是比较；题目是「没有很多反馈」，应表达数量不多，用 don't have much feedback。

10. 翻译：我们今天文件更少，但时间更多。

答案：

```
We have fewer files today, but we have much time.
```

批改：❌ 需要修改。

正确答案：

```
We have fewer files today, but we have more time.
```

解析：fewer files 正确；much time 是「很多时间」，more time 才是「更多时间」。

11. 改错（原意：他们每周开会）：They have meetings every weeks.

答案：

```
They have meetings every week.
```

批改：✅ 正确。every 后用了单数 week，「开会」的搭配也正确。

12. 翻译：我稍后会把报告发给你。（当场承诺）

答案：

```
I will send the report to you later.
```

批改：✅ 正确。will 表承诺正确；send the report to you 与 send you the report 都接受。

13. 改错：Do i have to ask for approval before deploy?

答案：

```
Do I have to ask for approval before deploy?
```

批改：❌ 需要修改。

正确答案：

```
Do I have to ask for approval before deploying?
```

解析：I 的大小写已改对；before 后不能直接接动词原形 deploy，这里用 deploying，也可以说 before the release。

14. 翻译：发布前，她不必申请批准。

答案：

```
She doesn't ask for approval before release.
```

批改：❌ 需要修改。

正确答案：

```
She doesn't have to ask for approval before the release.
```

解析：doesn't ask 表示「不申请」，doesn't have to ask 才是「不必申请」；这里指这次发布，用 before the release 自然。

15. 翻译：按照流程，他们必须核对这些数据。（可以用自己的表达）

答案：

```
They have to check these data as part of the process.
```

批改：✅ 正确。have to、check 和流程表达正确；these data 是正式的复数用法，接受，日常职场表达也常用 the data。

16. 翻译：你昨天为什么没有回复这条消息？

答案：

```
Why didn't you respond to this message yesterday?
```

批改：✅ 正确。Why didn't you + 原形、respond to、this 和 yesterday 都正确。
