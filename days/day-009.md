> 语法专题：`grammar/08-countable.md`

## Part 1 复习抽查

1. 改错：She is knowing the root cause, and she is responding a customer email now.

答案：

```
She knows the root cause, and she is responding to a customer email now.
```

2. 填空：Can you take a look **_ this PR? I don't have _** information yet.

答案：

```
Can you take a look at this PR? I don't have any information yet.
```

3. 翻译：她现在不能加班，但她可以回复几个请求。

答案：

```
She can't work overtime now, but she can respond to several requests.
```

## Part 2 语法复盘

阅读 `grammar/08-countable.md`，然后完成下面练习。

### 今日要点

1. **可数名词**可以数，单数前通常要有 `a / an / the`，复数可以接 `many / a few / some / any`。
2. **不可数名词**通常没有复数，也不直接加 `a / an`，如 `feedback / information / data / permission / time`。
3. **some / any**：肯定句常用 `some`；否定句和疑问句常用 `any`。
4. **many / much**：`many` 修饰可数复数；`much` 修饰不可数。
5. **a few / a little**：`a few` 修饰可数复数；`a little` 修饰不可数。

### 练习

1. 选词填空（some / any）：I have **_ feedback, but I don't have _** data.

答案：

```
I have some feedback, but I don't have any data.
```

2. 选词填空（many / much）：There aren't **_ requests today. We don't have _** time.

答案：

```
There aren't many requests today. We don't have much time.
```

3. 选词填空（a few / a little）：She has **_ files to review. I need _** information first.

答案：

```
She has a few files to review. I need a little information first.
```

4. 改错：I need an information and many feedback before the meeting.

答案：

```
I need some information and some feedback before the meeting.
```

5. 翻译：你有权限访问这些文件吗？

答案：

```
Do you have any permission to access these files?
```

正确答案：

```
Do you have permission to access these files?
```

解析：`permission` 是不可数名词，这里直接说 `have permission to...` 更自然，不需要加 `any`。

## Part 4 回译练习

把下面 **18 句中文** 译成英文。注意：可数复数用 `many / a few`，不可数用 `much / a little`；肯定句常用 `some`，否定句和疑问句常用 `any`。

1. 我有一些关于这个 PR 的反馈。

答案：

```
I have some feedback about this PR.
```

2. 你有任何关于这个 bug 的信息吗？

答案：

```
Do you have any information about this bug?
```

3. 我们现在没有任何数据。

答案：

```
We don't have any data yet.
```

4. 她今天早上收到了很多请求。

答案：

```
She got many requests this morning.
```

5. 我只需要一点时间来收尾这份报告。

答案：

```
We only need a little time to recap this report.
```

正确答案：

```
I only need a little time to wrap up this report.
```

解析：中文主语是「我」，要用 `I`；「收尾」这里用当天已学搭配 `wrap up`，不是 `recap`。

6. 我们有几个文件要检查。

答案：

```
We have a few files to check.
```

7. 这个共享网盘里有很多资源。

答案：

```
There are many resources in the shared drive.
```

8. 你想要一些咖啡吗？

答案：

```
Do you want some coffee?
```

9. 会议室里没有水。

答案：

```
There isn't any water in the meeting room.
```

10. 我现在正在等一些反馈。

答案：

```
I am waiting for some feedback.
```

11. 她正在处理几个请求。

答案：

```
She is working on a few requests.
```

12. 他现在没有在回复任何消息。

答案：

```
He didn't respond to any messages yet.
```

正确答案：

```
He isn't responding to any messages now.
```

解析：中文有「现在没有在……」，要用现在进行时否定 `isn't responding`，不是过去时 `didn't respond`。

13. 我需要权限访问这些文件。

答案：

```
I need some permissions to access these files.
```

正确答案：

```
I need permission to access these files.
```

解析：`permission` 是不可数名词，不能加复数 `-s`，这里也不需要 `some`。

14. 你有很多消息要回复吗？

答案：

```
Do you have many messages to respond?
```

正确答案：

```
Do you have many messages to respond to?
```

解析：`respond to` 是固定搭配，后面接对象时介词 `to` 不能省。

15. 我们没有太多时间修这个问题。

答案：

```
We don't have much time to fix this issue.
```

16. 她每天处理很多请求，但此刻她正在调试一个 bug。

答案：

```
She works on a lot of requests every day, but she is debugging a bug now.
```

17. 昨天会议室里没有很多人，但收件箱里有几条消息。

答案：

```
There aren't many people in the meeting room yesterday, but there are a few messages in the inbox.
```

正确答案：

```
There weren't many people in the meeting room yesterday, but there were a few messages in the inbox.
```

解析：`yesterday` 表示过去时间，`There are / aren't` 都要改成过去式 `There were / weren't`。

18. 你能发给我一些信息吗？我不能访问这些文件。

答案：

```
Can you send me some information? I can't access these files.
```

## 错题回顾

### 不可数名词

标签：`名词-不可数`、`表达-中式直译`

- Part 2-5「你有权限访问这些文件吗」：❌ Do you have any permission to access these files? → ✅ Do you have permission to access these files?
- Part 4-13「我需要权限访问这些文件」：❌ I need some permissions to access these files. → ✅ I need permission to access these files.

**规则**：`permission` 是不可数名词，通常直接说 `have permission` / `need permission`，不要写成 `a permission` 或 `permissions`。

### 信息与自然表达

标签：`信息-漏译`、`表达-中式直译`

- Part 4-5「我只需要一点时间来收尾这份报告」：❌ We only need a little time to recap this report. → ✅ I only need a little time to wrap up this report.
- Part 4-12「他现在没有在回复任何消息」：❌ He didn't respond to any messages yet. → ✅ He isn't responding to any messages now.

**规则**：主语、时间词和当天固定搭配都要落到英文里；看到「现在没有在……」优先用现在进行时否定。

### 固定搭配介词

标签：`搭配-介词`

- Part 4-14「你有很多消息要回复吗」：❌ Do you have many messages to respond? → ✅ Do you have many messages to respond to?

**规则**：`respond to + 对象` 是固定搭配，句尾也要保留 `to`。

### 过去时间

标签：`时态-过去式`

- Part 4-17「昨天会议室里没有很多人，但收件箱里有几条消息」：❌ There aren't many people in the meeting room yesterday, but there are a few messages in the inbox. → ✅ There weren't many people in the meeting room yesterday, but there were a few messages in the inbox.

**规则**：看到 `yesterday`，`There is / are` 也要切换成过去式 `There was / were`。
