## Part 1 复习抽查

1. 填空：She **_ (check) the logs every morning, but she _** (not check) them yesterday.

答案：

```
checks, didn't check
```

1. 改错：Here has many comments on PR.

答案：

```
There are many comments on PR.
```

正确答案：

```
There are many comments on the PR.
```

解析：特指这个 PR 时要加 the，PR 前不能直接省略冠词。

1. 选词填空（a / an / the / Ø）：I found **_ issue in _** login flow. issue blocks login.

答案：

```
I found a issue in the login flow. The issue blocks login.
```

正确答案：

```
I found an issue in the login flow. The issue blocks login.
```

解析：issue 以元音音开头，第一次提到单数可数名词要用 an issue。

1. 翻译：你能帮我看一下这个工单吗？

答案：

```
Can you help me with this ticket?
```

1. 改错：He cans join the meeting, but he didn't joined it yesterday.

答案：

```
He can join the meeting, but he didn't join it yesterday.
```

## Part 2 语法复盘

复习 `grammar/01-be-verbs.md` 到 `grammar/06-can-cant.md`，重点看下面 6 组句型。

### 语法要点回顾

1. **be 动词 + 主系表**：主语 + be + 名词 / 形容词 / 介词短语。表状态时直接用形容词，如 I am busy.
2. **一般现在时**：描述习惯、日常和固定安排。第三人称单数加 -s/-es，否定和疑问用 don't / doesn't / do / does。
3. **冠词 a / an / the**：第一次提到用 a/an，再次提到或双方已知用 the；复数泛指和不可数泛指常用零冠词。
4. **There is / There are**：表示「某处有……」，看后面名词选 is 或 are，不用 Here has。
5. **一般过去时**：明确过去时间用过去式；didn't / Did 后动词用原形；be 动词过去式是 was / were。
6. **can / can't**：can 后接动词原形，不随主语变化；请求用 Can you…? / Can I…? 更自然。

### 混合提醒

1. 看到 yesterday / last night / two days ago，先检查动词是不是过去式。
2. 看到 he / she / it + 日常动作，先检查动词有没有第三人称单数。
3. 看到单数可数名词，先问自己要不要 a/an/the。
4. 看到「某处有」，优先用 There is / There are。
5. 看到「能不能帮我……」，直接用 Can you…?，不要写 You can…?

## Part 4 回译练习

把下面 **18 句中文** 译成英文。注意混合使用前 6 天的语法：be 动词、一般现在时、冠词、There is/are、一般过去时、can/can't。

1. 我是一名后端工程师，现在在办公室。

答案：

```
I am a backend engineer, I am in the office now.
```

正确答案：

```
I am a backend engineer. I am in the office now.
```

解析：两个完整句子不能只用逗号连接，要用句号或 and。

1. 她通常午饭前审查代码。

答案：

```
She usually reviews code before lunch.
```

1. 产品经理每周五写一份周报。

答案：

```
The product manager writes a weekly report every Friday.
```

1. 我昨天在登录流程里发现了一个 bug。

答案：

```
I found a bug in the login flow yesterday.
```

答案：

```
This bug blocks the login.
```

正确答案：

```
This bug blocks login.
```

解析：这里的 login 表登录行为或登录流程，作泛指时通常不用 the。

1. 我的收件箱里有三张工单。

答案：

## 错题回顾

### 冠词与特指

- Part 1-2「Here has many comments on PR」：❌ There are many comments on PR. → ✅ There are many comments on the PR.
- Part 1-3「I found _ issue」：❌ I found a issue in the login flow. → ✅ I found an issue in the login flow.
- Part 4-5「这个 bug 会挡住登录」：❌ This bug blocks the login. → ✅ This bug blocks login.
- Part 4-16「部署到测试环境」：❌ deploys to test environment → ✅ deploys to the test environment

**规则**：单数可数名词首次提到用 a/an，特指对象用 the；有些抽象动作如 login 作泛指时不用冠词。

### 句子连接与自然表达

- Part 4-1「我是一名后端工程师，现在在办公室」：❌ I am a backend engineer, I am in the office now. → ✅ I am a backend engineer. I am in the office now.
- Part 4-14「你能帮我看一下这个 PR 吗」：❌ Can you help me with this PR? → ✅ Can you take a look at this PR?

**规则**：两个完整句不要只用逗号连接；「看一下」优先用 take a look at。

### 时态与信息完整

- Part 4-17「昨天会议室里有很多人」：❌ There are many people → ✅ There were many people in the meeting room yesterday.
- Part 4-18「我今天不能加班」：❌ I can't work overtime → ✅ I can't work overtime today

**规则**：看到 yesterday 要切到过去式；中文里的时间和地点信息要完整落到英文里。
