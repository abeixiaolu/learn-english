## Part 2 语法复盘

### 1. 先分原因和结果

原因回答“为什么”，结果回答“因此怎么样”。例如“他生病了，因此不能加班”：生病是原因，不能加班是结果。连接前，先分别确定两部分的意思。

### 2. because 后面说明原因

结构：结果句 + because + 原因句。

He cannot work overtime because he is sick.（他不能加班，因为他生病了。）

because 后接完整的句子：要说清“谁做什么”或“谁是什么状态”。即使两个分句说的是同一个人，通常也要保留各自的主语。这里紧密相连的 because 原因句前通常不加逗号。

### 3. so 后面说明结果

结构：原因句 + , so + 结果句。

The keyboard is broken, so I am going to use that laptop.（键盘坏了，所以我打算用那台笔记本电脑。）

同一组因果关系选 because 或 so 连接，不把两者重复放进同一句。连接词不代替 be，也不改变三单、过去式、情态动词后用原形等规则。

### 4. 时间要同时表达日期和钟点

具体钟点用 at；上午可用 a.m.，下午可用 p.m.。例如：She has a meeting at 2 p.m. tomorrow.（她明天下午两点有一场会议。）

使用 o'clock 时，可以另外接 this afternoon、this morning 等时段表达；不能把 morning 直接接在 o'clock 后。today、tomorrow、this morning 等时间短语前不再加 in 或 on。

题目把“不必”限定在某一天时，要明确保留那一天。写完逐个分句检查人物、日期、钟点和地点；当前语境已经清楚表达“现在”时，不必机械重复 now。

### 练习

按要求连接或填空；保留全部信息。

1. 用 because 连接，先说结果：She cannot share her screen now. Her laptop is offline.

答案：

```
She cannot share her screen now because her laptop is offline.
```

2. 用 so 连接，先说原因：These files are ready. We can review them today.

答案：

```
These files are ready, so we can review them today.
```

3. 填入正确形式：He **_ (review) the schedule every morning because he _** (have) meetings every day.

答案：

```
reviews, has
```

4. 用 so 连接，保留全部信息：We found an issue at 3 p.m. yesterday. We must update that report today.

答案：

```
We found an issue at 3 p.m. yesterday, so we must update that report today.
```

## Part 4 回译练习

按指定连接词作答。前 13 题巩固因果表达，后 5 题结合旧错点；逐个分句核对信息。

1. 连接很弱，所以我现在不能加入通话。（用 so）

答案：

```
The connection is weak, so I cannot join the call now.
```

2. 我们现在不能部署，因为连接不稳定。（用 because）

答案：

```
We cannot deploy now because the connection is not stable.
```

3. 连接很稳定，所以她现在可以共享屏幕。（用 so）

答案：

```
The connection is stable, so she can share her screen now.
```

4. 这份报告准备好了，所以我们今天可以审查它。（用 so）

答案：

```
This report is ready, so we can review it today.
```

5. 我们今天不能在食堂里开会，因为那里很拥挤。（用 because）

答案：

```
We cannot have a meeting in the cafeteria today because it is crowded.
```

6. 她现在有空，所以你现在可以问她。（用 so）

答案：

```
She is available now, so you can ask her now.
```

7. 我们今天可以在那个会议室开会，因为它是空闲的。（用 because）

答案：

```
We can have meetings in that meeting room today because it is free.
```

8. 这个备份是安全的，所以我们今天不必更新它。（用 so）

答案：

```
This backup is safe, so we don't have to update it today.
```

9. 我们今天不应该部署，因为这个改动有风险。（用 because）

答案：

```
We shouldn't deploy today because this change has risky.
```

正确答案：

```
We shouldn't deploy today because this change is risky.
```

解析：risky 是形容词，表达“有风险的”用 is risky；has 后不能直接接形容词，也可用 has risks，但本课用 is risky 更直接。

10. 这个备份很重要，所以你应该再核对一遍它。（用 so）

答案：

```
This backup is important, so you should double-check it.
```

11. 我现在不能保存这个文件，因为我的笔记本电脑有一个问题。（用 because）

答案：

```
I cannot save this file because my computer has an issue.
```

正确答案：

```
I cannot save this file now because my laptop has an issue.
```

解析：computer 只表示电脑，未明确题干中的“笔记本电脑”，应使用已学的 laptop；本题 cannot save 在当前语境下可表达“现在不能保存”，不因未单写 now 扣分。

12. 这份文档准备好了，所以我现在会保存它。（用 so；当场决定）

答案：

```
This document is ready, so I will save it now.
```

13. 我们今天必须保存这些文件，因为它们很重要。（用 because）

答案：

```
We must save these files today because they are important.
```

14. 他现在正在阳台上看那份报告，因为那里很安静。（用 because；前半句用现在进行时）

答案：

```
He is reading that report on the balcony now because that is quiet.
```

正确答案：

```
He is reading that report on the balcony now because it is quiet there.
```

解析：“那里很安静”可用 it is quiet there，或 because the balcony is quiet；that is quiet 的指代不清，没有自然表达这里的地点状态，前半句的进行时、read 和 on the balcony 均正确。

15. 她今天上午八点必须在入口处等我们，所以她不能参加今天上午的会议。（用 so）

答案：

```
She must wait for us at the entrance at 8 a.m. today, so she cannot have the meeting this morning.
```

正确答案：

```
She must wait for us at the entrance at 8 a.m. today, so she cannot attend the meeting this morning.
```

解析：参加会议用 attend the meeting 或 join the meeting；have the meeting 偏向举行、进行会议，不能准确表达本题的个人参会；日期、钟点和入口处均表达正确。

16. 我们今天不必使用那台打印机，因为它坏了。（用 because）

答案：

```
We don't have to use that printer today because it is broken.
```

17. 他昨天上午十点在食堂里发现了一个问题，所以他今天必须更新那份报告。（用 so）

答案：

```
He found an issue in the cafeteria at ten o'clock yesterday morning, so he must update that report today.
```

18. 她现在很忙，所以我今天下午四点会问她。（用 so；当场决定）

答案：

```
She is busy now, so I will ask her at 4 p.m. today.
```

## 错题回顾

### 形容词表达状态要用 be

标签：`表达-中式直译`

- Part 4-9：❌ this change has risky → ✅ this change is risky。

**规则**：中文“有风险”不直接套 has + 形容词；risky 表示“有风险的”，与 be 连用。

### 保留物品的具体类别

标签：`信息-漏译`

- Part 4-11：❌ my computer → ✅ my laptop。

**规则**：computer 是较宽泛的电脑，laptop 明确表示笔记本电脑；题干给出具体类别且已学对应词时，应保留该信息。当前语境中未单写 now 不另计错。

### 地点状态的指代

标签：`表达-中式直译`

- Part 4-14：❌ because that is quiet → ✅ because it is quiet there。

**规则**：表达“那里很安静”可用 it is quiet there，也可直接以地点名词作主语，避免用指代不清的 that 代替整个地点状态。

### 参加会议与举行会议

标签：`语义-词义`

- Part 4-15：❌ she cannot have the meeting this morning → ✅ she cannot attend the meeting this morning。

**规则**：个人“参加会议”用 attend / join the meeting；have a meeting 通常表达开会或进行一场会议。本题中的 attend 作为批改补充词，不作为已掌握词。
