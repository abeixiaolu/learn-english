## Part 1 复习抽查

先不看下面的讲解和词表，独立写出英文。

<a name="part-1-1"></a>
1. 如果这家面包店明天开门，我们就会去买面包。

答案：

```
If this bread market open tomorrow, we will go to buy bread.
```

批改：❌ **If this bakery is open tomorrow, we will go and buy bread.** “面包店”常说 bakery；表示明天营业，可用 is open，或用 opens 表示开门营业。

<a name="part-1-2"></a>
2. 那家小餐馆很热闹，所以我们昨天晚上在外面等了二十分钟。

答案：

```
That little resterlunt is busy, so we waited for it twenty minutes outside last night.
```

批改：❌ **That little restaurant was busy, so we waited outside for twenty minutes last night.** restaurant 的拼写要调整；这里说在外面等了多久，用 waited outside for twenty minutes。

<a name="part-1-3"></a>
3. 虽然这个公园很吵，但她今天下午仍然打算在那里散步。

答案：

```
Although this park is noisy, she still walk there this afternoon.
```

批改：❌ **Although this park is noisy, she is still going to take a walk there this afternoon.** “打算”需要表达出来，如 is going to；它后面的动词用原形。

## Part 2 语法复盘

### 1. 到现在为止有没有这样的经历

我们有时不想说事情是哪天发生的，只想说一个人**到目前为止是否有过某种经历**。这时可以用现在完成时。它把过去的经历和“现在回答这个问题”联系起来，不要求交代具体日期。

例如：**I have tried Thai food.**（我吃过泰国菜。）这里想表达的是“有这个经历”，不是说是哪一天吃的。

### 2. 基本形式

肯定句：**主语 + have / has + 过去分词**。

- I、you、we、they 后用 **have**；he、she、it 或单数名词后用 **has**。
- 过去分词是动词的一种形式。有些规则动词在词尾加 -ed，例如 clean → cleaned；有些是不规则变化，例如 write → written。
- 口语和日常写作中常缩写：I've、we've、she's。这里的 she's 要结合上下文判断：在过去分词前，它可以是 she has 的缩写。

例如：**My uncle has written a short story.**（我叔叔写过一个短篇故事。）

### 3. 问有没有过；回答有没有过

一般疑问句把 have 或 has 放到主语前：**Have / Has + 主语 + 过去分词？**

例如：**Have they ever ridden a horse?**（他们骑过马吗？）**ever** 在这里表示“曾经”，通常放在主语后、过去分词前。回答可以简短说 **Yes, they have.** 或 **No, they haven't.**

说“从来没有”可以用 **never**：**主语 + have / has + never + 过去分词**。例如：**She has never flown in a helicopter.**（她从来没有坐过直升机。）never 本身已经表达否定，不再加 not。

也可以用 **haven't / hasn't + 过去分词** 表示没有做过某事。否定形式里的 have 和 has 与肯定句一样随主语变化。

### 4. 别把“有过经历”和“哪天发生”混在一起

**I have watched that film.** 侧重“我看过那部电影”，没有说具体时间。**I watched that film last Friday.** 说的是上周五发生的事，用一般过去时。

当题目明确说 yesterday、last week 等已经结束的具体过去时间，通常用一般过去时；不要把这些时间直接和本课的现在完成时经历句连用。回答自己的真实经历时，可以先说有没有过，再另用过去时补充具体时间。

## Part 3 词汇

| 词 / 搭配       | 意思                  | 生活例句                                       |
| --------------- | --------------------- | ---------------------------------------------- |
| ever            | 曾经；常用于询问经历  | Have you ever cooked for a large group?        |
| never           | 从来没有              | My brother has never climbed a mountain.       |
| try → tried     | 尝试 → 过去分词       | I've tried that little café near the station.  |
| visit → visited | 参观；拜访 → 过去分词 | They've visited their grandparents this month. |
| eat → eaten     | 吃 → 过去分词         | She has eaten lunch already.                   |
| make → made     | 制作 → 过去分词       | We've made some sandwiches.                    |
| see → seen      | 看见；观看 → 过去分词 | He's seen a rainbow before.                    |

只需要记住今天用得到的形式；词表表示接触过，不表示已经掌握。

## Part 4 回译练习

先按提示完成前几题，后面自己选择表达方式。除第 10 题明确说了过去时间，其他题主要关注有没有经历，不必添加具体日期。

<a name="part-4-1"></a>
1. 我尝试过这道菜。（提示：I + have + tried）

答案：

```
I have tried this food.
```

批改：✅ 正确。表达“这道菜”时，也可以用 **this dish**。

<a name="part-4-2"></a>
2. 她参观过那个美术馆。（提示：She + has + visited）

答案：

```
She has visited that art museaum.
```

批改：❌ **She has visited that art museum.** 现在完成时结构正确；museum 的拼写需要调整。

<a name="part-4-3"></a>
3. 你曾经自己做过面包吗？（提示：Have you ever ...？）

答案：

```
Have you ever made bread by yourself?
```

批改：✅ 正确。

<a name="part-4-4"></a>
4. 我从来没有看过这部电影。（提示：never 放在 have 和过去分词之间。）

答案：

```
I have never watched this movie.
```

批改：✅ 正确。

<a name="part-4-5"></a>
5. 他们吃过这家店的甜点吗？请用英文写出问题，再写一个简短的否定回答。

答案：

```
Have they eaten this shop's sweet cake?
Yes they have.
```

批改：❌ **Have they eaten dessert from this shop? No, they haven’t.** 问句结构正确，但题目要求否定回答；sweet cake 也缩小了“甜点”的范围。

<a name="part-4-6"></a>
6. 我们尝试过这个做法，但它太辣了。

答案：

```
We have tried this method, but it's too spicy.
```

批改：✅ 正确。这里谈烹饪做法时，也可以用 **this recipe**。

<a name="part-4-7"></a>
7. 她从来没有给朋友做过生日蛋糕。

答案：

```
She has never made birthday cake for friends.
```

批改：❌ **She has never made a birthday cake for her friends.** 单数可数名词 birthday cake 前通常需要 a；for friends 可以表达给朋友。

<a name="part-4-8"></a>
8. 你看过这本书里的照片吗？

答案：

```
Have you watched the photo inside of this book?
```

批改：❌ **Have you seen the photos in this book?** 表达看过静态照片通常用 seen，而不是 watched。

<a name="part-4-9"></a>
9. 我吃过这种水果，我很喜欢它。

答案：

```
I have eaten this fruit, and I like it.
```

批改：✅ 正确。

<a name="part-4-10"></a>
10. 我上周六和家人参观了那个公园。

答案：

```
I visited that park with my family last Saturday.
```

批改：✅ 正确。

```
I have tried 寿司 again in the JiuJin resturant, but I still can't adapt this taste. If I have any chance to japan, I still retry it again.
```
