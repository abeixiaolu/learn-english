## Part 1 复习抽查

1. 填空：I \_\_\_ (check) the logs yesterday. She \_\_\_ (review) the PR last night.

答案：

```
checked, reviewed
```

2. 改错：He didn't fixed the bug yesterday.

答案：

```
He didn't fix the bug yesterday.
```

3. 翻译：会议室里有一块白板。

答案：

```
There is a white board in the meeting room.
```

正确答案：

```
There is a whiteboard in the meeting room.
```

解析：whiteboard 是一个词，不要写成 white board。

## Part 2 语法复盘

阅读 `grammar/06-can-cant.md`，然后完成下面练习。

### 今日要点

1. **can / can't**：表示能力、请求或许可，后接动词原形。
2. **不变人称**：没有 cans；He can / She can / They can。
3. **疑问**：Can + 主语 + 动词原形？——Can you help me?
4. **否定**：can't / cannot + 动词原形——I can't join the meeting.
5. **纠偏**：请求用 Can you…?，比「你能不能……」的直译更直接自然。

### 练习

1. 填空：She \_\_\_ write unit tests. He \_\_\_ access the staging server.

答案：

```
can, can't
```

2. 改错：He cans deploy the service. I can't joining the call.

答案：

```
He can deploy the service. I can't join the call.
```

3. 改错：You can help me with this ticket?

答案：

```
Can you help me with this ticket?
```

4. 翻译：我今天不能加班。

答案：

```
I can't work overtime.
```

正确答案：

```
I can't work overtime today.
```

解析：中文有「今天」，要把 today 译出来。

5. 翻译：你能把日志发给我吗？

答案：

```
Can you send me the logs?
```

## Part 4 回译练习

把下面 **18 句中文** 译成英文。注意：can 后接**动词原形**；请求用 **Can you…?** / **Can I…?**。

1. 我会写 SQL 查询。

答案：

```
I can write sql queries.
```

正确答案：

```
I can write SQL queries.
```

解析：SQL 是专有缩写，通常大写。

2. 她会写单元测试。

答案：

```
She can write unit tests.
```

3. 他能部署这个服务。

答案：

```
He can deploy this service.
```

4. 我能在我的机器上运行这个脚本。

答案：

```
I can run this script on my machine.
```

5. 我今天不能加入会议。

答案：

```
I cannot join the meeting today.
```

6. 他不能访问预发服务器。

答案：

```
He cannot access the stage server.
```

正确答案：

```
He can't access the staging server.
```

解析：预发环境说 staging server，不是 stage server；cannot 也可，职场口语更常 can't。

7. 她今天早上不能加入通话。

答案：

```
She can't join the call this morning.
```

8. 我们今天下午不能加班。

答案：

```
We can't work overtime this afternoon.
```

9. 你能帮我看一下这个工单吗？

答案：

```
Can you help me to look at this ticket?
```

正确答案：

```
Can you help me with this ticket?
```

解析：今天练的搭配是 help sb with；也可用 Can you take a look at this ticket?

10. 你能把日志发给我吗？

答案：

```
Can you send me the logs?
```

11. 你能看一下这个 PR 吗？

答案：

```
Can you look at this PR?
```

12. 你能共享一下屏幕吗？

答案：

```
Can you share your screen?
```

13. 你能复现这个 bug 吗？

答案：

```
Can you reproduce this bug?
```

14. 你能帮我一下吗？

答案：

```
Can you give me a hand?
```

15. 我可以今天早点离开吗？

答案：

```
Can we leave early today?
```

正确答案：

```
Can I leave early today?
```

解析：中文是「我可以」，主语用 I，不是 we。

16. 我可以看一下你的屏幕吗？

答案：

```
Can I take a look your screen?
```

正确答案：

```
Can I take a look at your screen?
```

解析：take a look 后面要加 at。

17. 你能大声一点说吗？

答案：

```
Can you speak up?
```

18. 你能等一分钟吗？

答案：

```
Can you wait a minute?
```

## 错题回顾

### 固定搭配与专有写法

- Part 1-3「会议室里有一块白板」：❌ white board → ✅ whiteboard
- Part 4-1「我会写 SQL 查询」：❌ sql → ✅ SQL
- Part 4-6「他不能访问预发服务器」：❌ stage server → ✅ staging server
- Part 4-9「你能帮我看一下这个工单吗」：❌ help me to look at → ✅ help me with / take a look at

**规则**：白板写成 whiteboard；SQL 大写；预发是 staging；帮忙用 help sb with，看一眼用 take a look at。

### 信息漏译与主语

- Part 2-4「我今天不能加班」：❌ I can't work overtime. → ✅ I can't work overtime today.
- Part 4-15「我可以今天早点离开吗」：❌ Can we… → ✅ Can I…

**规则**：中文里的「今天 / 我」要落到英文里，别漏时间词，也别换错主语。

### 介词缺失

- Part 4-16「我可以看一下你的屏幕吗」：❌ take a look your screen → ✅ take a look at your screen

**规则**：take a look at + 名词，at 不能省（也可说 Can I look at your screen?）。
