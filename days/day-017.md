## Part 2 语法复盘

### 1. 日常动作：先看主语，再看有没有 does

一般现在时用来描述习惯或通常发生的事。主语是 he / she / it 或单个人、物时，肯定句的动作动词通常加 -s / -es。主语是 I / you / we / they 时用原形。

例句：`The backend team reviews the plan every week.`（后端团队每周审查计划。）这里把 team 看作一个整体。

否定和提问用 do / does 帮忙。用了 does / doesn't，动作动词恢复原形：**Does + 主语 + 原形？**；**主语 + doesn't + 原形**。例句：`Does this script run?`（这个脚本能运行吗？）

usually 通常放在动作动词前；every 后接单数时间单位，如 every day、every week。

### 2. 数量：先区分“多少”和“比之前多或少”

file、request、message 能逐个数，是可数名词；time、feedback、water 通常按整体看，是不可数名词。

| 中文意思   | 可数复数 | 不可数   |
| ---------- | -------- | -------- |
| 很多       | many     | much     |
| 一些、少量 | a few    | a little |
| 更多       | more     | more     |
| 更少       | fewer    | less     |
| 没有很多   | not many | not much |

“更少”是在比较；“没有很多”是在说数量不多，不一定有比较对象。“更多”和“很多”也要区分。肯定句表达很多时，a lot of 可修饰可数复数或不可数名词。

例句：`I have a little coffee.`（我有一点咖啡。）`This option needs less information.`（这个选项需要更少的信息。）

### 3. 否定：不做、不必做、禁止做

**don't / doesn't + 动词原形** 描述不做某事；**don't / doesn't have to + 动词原形** 表示没有义务，做不做都可以；**mustn't + 动词原形** 表示禁止。

例句：`They don't work on this ticket.`（他们不处理这张工单。）`They don't have to work on this ticket.`（他们不必处理这张工单。）`You mustn't access this server.`（你禁止访问这台服务器。）

肯定句表示必须时，he / she / it 用 has to，其他常见主语用 have to；否定与提问用了 does 后，has 恢复为 have。should 是建议，后接原形，否定是 shouldn't。

### 4. before：后面接什么，决定词形

before 表示“在……之前”。后面可以接名词，或表示动作的 -ing 形式；不能直接放一个动作动词原形。指双方已知的某次发布时，可用名词短语 the release。

例句：`I review the plan before joining the call.`（加入通话前，我审查计划。）join 变为 joining。以不发音的 e 结尾的动词通常去 e 加 -ing，如 migrate → migrating。

before 也可以接完整句子：`We check the data before we send the report.`（发送报告前，我们检查数据。）完整句子里有自己的主语和动词，不能把这种结构和单独接 -ing 混淆。

### 5. 混合检查：时间和提问语序

明确的过去动作：肯定句用过去式，did / didn't 后用原形。正在发生的动作：用 am / is / are + -ing；need、know 等状态动词通常用一般现在时。

be 的否定疑问可以缩写为 **Isn't / Aren't + 主语 …？**，不缩写则是 **Is / Are + 主语 + not …？**。

例句：`Aren't they waiting for feedback?`（他们不是在等反馈吗？）

写完核对：谁在做、什么时间、是否有义务、数量有没有比较。保留 respond to 等搭配里的介词，第一人称 I 始终大写。

### 练习

1. 填空：He usually \_\_\_ (confirm) the schedule.

答案：

```
confirms
```

2. 选词填空（many / more）：We don't have \_\_\_ requests today.（今天请求不多，不作比较）

答案：

```
many
```

3. 改成表示“不必”的否定句：She has to upgrade the server today.

答案：

```
She don't have to upgrade the server today.
```

正确答案：

```
She doesn't have to upgrade the server today.
```

解析：主语 She 是第三人称单数，否定用 doesn't，后面的 have 和 upgrade 保持原形。

4. 填空：Please check the data before \_\_\_ (submit) the report.

答案：

```
submitting
```

5. 改成不使用缩写的否定疑问句：They are debugging now.

答案：

```
Are they not debugging now?
```

## Part 4 回译练习

1. 他通常审查工单。

答案：

```
He usually reviews the ticket.
```

2. 我的同事每天更新这份文档。

答案：

```
My colleague updates this document every day.
```

3. 她每周都检查这些文件吗？

答案：

```
Does she check these files every week?
```

4. 他今天不需要任何反馈。

答案：

```
He doesn't need any feedback.
```

正确答案：

```
He doesn't need any feedback today.
```

解析：否定和 any feedback 都正确，但漏译了“今天”，需要补上 today。

5. 我们有一些请求，但没有很多反馈。

答案：

```
We have some requests, but we don't have much feedback.
```

6. 我们今天消息更少，但反馈更多。（与昨天相比）

答案：

```
We have fewer messages today, but we have more feedback.
```

7. 他们没有很多文件，但有很多时间。

答案：

```
They don't have many files, but they have much time.
```

表达建议（不计错）：much time 在肯定句中语法成立，但日常表达更常用 a lot of time：They don't have many files, but they have a lot of time。

8. 这个计划需要更多时间。（与另一个计划相比）

答案：

```
This plan needs more time.
```

9. 这个选项需要更少的数据。（与另一个选项相比）

答案：

```
This option needs less data.
```

10. 她今天不提交这份报告。

答案：

```
She doesn't submit this report today.
```

11. 她今天不必提交这份报告。

答案：

```
She doesn't have to submit this report today.
```

12. 按照流程，他必须申请批准。（可以用自己的表达）

答案：

```
Follow the process, he must ask for approval.
```

正确答案：

```
According to the process, he must ask for approval.
```

解析：Follow the process 是“遵循流程”的祈使句，不能用逗号直接接后面的陈述句；“按照流程”可用 According to the process。

13. 你禁止访问这台预发服务器。

答案：

```
You mustn't access this staging server.
```

14. 部署前，我们应该再核对一遍这些数据。（before 后接部署动作）

答案：

```
We should double check these data before deploying.
```

15. 发布前，他不必更新这份文档。（用名词表达这次发布）

答案：

```
He doesn't have to update this document before release.
```

表达建议（不计错）：before release 是可接受的流程表达；题目强调“这次发布”，用 before the release 能更明确地指这一次发布。

16. 提交这份报告前，我必须检查这些数据吗？（before 后接提交动作）

答案：

```
I must check these data before submitting this report.
```

正确答案：

```
Must I check these data before submitting this report?
```

解析：题目是疑问句，情态动词 must 要放到主语 I 前，并以问号结尾；these data 是可接受的正式复数用法。

17. 他昨晚写了这份文档，但没有把它发给我。

答案：

```
Although he wrote this document last night, he didn't send it to me.
```

18. 她现在不是在准备报告吗？（用不缩写的否定疑问句）

答案：

```
Is she not preparing the report now ?
```

## 错题回顾

### 不做与不必做

标签：`语义-不必`

- Part 1-3「你今天不必提交这份报告。」：❌ You don't submit this report today. → ✅ You don't have to submit this report today.

**规则**：don't + 动词表示“不做”；don't have to + 动词表示“不必做”，做不做都可以。

### 第三人称单数的否定

标签：`时态-三单`

- Part 2-3「改成表示“不必”的否定句：She has to upgrade the server today.」：❌ She don't have to upgrade the server today. → ✅ She doesn't have to upgrade the server today.

**规则**：he / she / it 的一般现在时否定用 doesn't + 原形；has to 变为 doesn't have to。

### 时间信息漏译

标签：`信息-漏译`

- Part 4-4「他今天不需要任何反馈。」：❌ He doesn't need any feedback. → ✅ He doesn't need any feedback today.

**规则**：译完核对题干中的时间、对象和限定词，不要只检查动词形式。

### 按照流程的表达

标签：`表达-中式直译`、`句式-逗号连接`

- Part 4-12「按照流程，他必须申请批准。」：❌ Follow the process, he must ask for approval. → ✅ According to the process, he must ask for approval.

**规则**：表达“按照流程”可用 according to the process；Follow the process 是独立的命令，不能用逗号直接接一个陈述句。

### 情态动词疑问句

标签：`句式-疑问语序`

- Part 4-16「提交这份报告前，我必须检查这些数据吗？」：❌ I must check these data before submitting this report. → ✅ Must I check these data before submitting this report?

**规则**：含 must 的一般疑问句用 Must + 主语 + 动词原形 …?；也可用 Do I have to …?。
