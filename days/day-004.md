# Day 004 — There is / There are

> 语法专题：`grammar/04-there-is-are.md`

---

## Part 1 复习抽查

1. 填空：She \_\_\_ (review) code before lunch every day.

答案：

```
reviews
```

2. 改错：I found bug in logs. Bug is critical.

答案：

```
I found a bug in the logs. The bug is critical.
```

3. 翻译：他是我们团队的产品经理。

答案：

```
He is the product manager of our team.
```

正确答案：

```
He is the product manager on our team.
```

解析：团队搭配是 on our team，不是 of our team（同 Day 003）。

## Part 2 语法复盘

阅读 `grammar/04-there-is-are.md`，然后完成下面练习。

### 今日要点

1. **There is / There are**：表示「某处有……」，看后面名词选 is 还是 are。
2. **否定与疑问**：There isn't / aren't；Is there …? / Are there …?
3. **some / any / no**：肯定用 some，否定疑问用 any，也可用 no。
4. **纠偏**：不说 Here has… / Office has…，改用 There is/are + 地点。
5. **There is vs have**：存在用 there is；拥有用 have/has。

### 练习

1. 填空：There \_\_\_ (be) a standup at 10 a.m. There \_\_\_ (be) three open tickets.

答案：

```
There is a standup at 10 a.m. There are three open tickets.
```

2. 改错：Here has many people in the meeting room. Office has a printer.

答案：

```
There are many people in the meeting room. There is a printer at the office.
```

3. 选词填空（some / any / no）：There aren't \_\_\_ blockers. Are there \_\_\_ questions?

答案：

```
There aren't any blockers. Are there any questions?
```

4. 翻译：桌上有两台显示器。

答案：

```
There are two monitors on the desk.
```

5. 翻译：今天下午有会议吗？

答案：

```
Is there a meeting this afternoon?
```

## Part 4 回译练习

把下面 **18 句中文** 译成英文。注意：**用 There is/are 表存在**；不要写成 Here has… / 地点 + has…。

1. 登录流程里有一个 bug。

答案：

```
There is a bug in the login flow.
```

2. 我的收件箱里有三张工单。

答案：

```
There are three tickets in my inbox.
```

3. 会议室里有一块白板。

答案：

```
There is a whiteboard in the meeting room.
```

4. 我的桌上有两台显示器。

答案：

```
There are two monitors on my desk.
```

5. 办公室里有一台打印机吗？

答案：

```
Is there a printer in the office?
```

6. 这个 PR 上有一些评论。

答案：

```
There are some comments on the PR.
```

7. 现在没有任何阻塞项。

答案：

```
There aren't any blockers now.
```

8. 这个 sprint 里没有未关闭的问题。

答案：

```
There aren't any open issues in the sprint.
```

正确答案：

```
There aren't any open issues in this sprint.
```

解析：中文是「这个 sprint」，用 this sprint；也可用 There are no open issues in this sprint。

9. 走廊里有三间会议室。

答案：

```
There are three meeting rooms in the hallway.
```

10. 演示前还剩一点时间。

答案：

```
There is some leftover time before the demo.
```

11. 测试环境里有一个配置错误。

答案：

```
There is a config error in the test environment.
```

12. 共享盘里有一份文档。

答案：

```
There is a document in the shared drive.
```

13. 今天下午有站会吗？

答案：

```
Are there any standup meetings this afternoon?
```

正确答案：

```
Is there a standup this afternoon?
```

解析：「有一场站会」用单数 Is there a standup；Are there any… 暗示可能有多场。

14. 这里有很多人。（纠偏：不要用 Here has）

答案：

```
There are many peoples here.
```

正确答案：

```
There are many people here.
```

解析：people 本身已是复数，不能再加 -s；peoples 指多个民族/族群。

15. 日志里有几个警告。

答案：

```
There are a few warnings in the logs.
```

16. 工位上没有笔记本电脑。

答案：

```
There is no laptop on the desk.
```

17. 后端团队有一个新同事。（提示：存在「有一个人」用 There is）

答案：

```
There is a new colleague on backend team.
```

正确答案：

```
There is a new colleague on the backend team.
```

解析：特指后端团队要加 the——on the backend team（同 on our team）。

18. 我们的看板里有太多任务。

答案：

```
There are too many tasks in our kanban.
```

正确答案：

```
There are too many tasks on our kanban board.
```

解析：看板完整说法是 kanban board；任务在看板上用 on。

## 错题回顾

### 固定搭配 on the team

- Part 1-3「我们团队的产品经理」：❌ of our team → ✅ on our team
- Part 4-17「后端团队有一个新同事」：❌ on backend team → ✅ on the backend team

**规则**：团队前用 on，且特指时加 the——on our team / on the backend team。

### 单复数与集合名词

- Part 4-13「今天下午有站会吗」：❌ Are there any standup meetings → ✅ Is there a standup
- Part 4-14「这里有很多人」：❌ many peoples → ✅ many people

**规则**：一场会用 Is there a…；people 已是复数，不要写成 peoples。

### 指代与完整名词

- Part 4-8「这个 sprint 里没有…」：❌ in the sprint → ✅ in this sprint
- Part 4-18「看板里有太多任务」：❌ in our kanban → ✅ on our kanban board

**规则**：「这个」对应 this；专有说法写全（kanban board），并注意 in/on 搭配。
