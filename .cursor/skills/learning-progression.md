# 语法推进规则

生成课程和批改后的下一课建议都使用本规则。

## 判断依据

- 分开判断「本课目标语法」和「其他错误」。例如 because / so 的目标是因果方向、连接方式和两个分句的完整结构；laptop 词义、时间漏译、形容词前漏 be 等分别记录为词汇、信息或基础语法问题，不能直接判成 because / so 未掌握。
- 依据最近已批改的独立作答，查看目标语法在不同句子中是否稳定正确。整题正确率、全天总分和错题总数不能代替目标语法判断；尚未作答、照抄订正和课程已生成都不算独立掌握证据。
- 最近两次已批改课程中，目标语法在多道不同题里持续正确、没有反复出现的核心误解时，下一普通日默认推进。证据充分时也可更早推进，不要求零错误或满分。

## 如何安排下一课

- 达到推进条件：新语法作为下一课主线，旧错点放入 Part 1 和少量回译题，遵守 daily-study 原有的错题反哺比例。Part 1 与新课可以在同一文件中生成，不必先等 Part 1 批改通过才提供新课。
- 继续巩固原单元：必须列出最近作答中仍存在的目标语法错误及题号，并围绕该问题安排换场景练习；仅有零散词汇、搭配、拼写、漏译或旧语法错误时，采用局部复查，不重复整天原单元。仅为“再确认一次”或“还不能认定长期掌握”不足以延长单元。
- 重复同一单元前，检查已连续安排的天数与新证据。天数本身不是掌握标准；连续安排越久，越要检查是否把其他错误误当成当前语法问题。用户明确要求专项巩固、计划中的周期复习或中断后恢复学习，按对应安排执行。
- 已达到推进条件但 PLAN.md 尚未列出下一单元时，按现有难度顺序补充一个衔接自然的小单元并同步计划，不能因大纲暂缺而重复已通过单元。
- 在批改小结和 PLAN.md 中分别记录「目标语法表现」「待复查旧错点」「下一课主线」，并给出题号或本轮表现依据。旧的“先复查再推进”建议应根据最新证据更新，不能无限沿用。

## 判断示例

because / so 连续两课方向和结构正确，但仍出现 is risky、地点指代或参加会议的表达问题：推进下一单元，将这些问题穿插复习。若仍反复颠倒原因与结果，或同一因果关系重复使用 because 和 so，则针对这些核心问题巩固。
