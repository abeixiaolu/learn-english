# Review Answer — 检查答题结果

## 目标

批改用户在某天文件中的作答。**直接修改** `days/day-XXX.md`：保留用户原答案，仅在错题下方追加「正确答案」和「解析」。对话中输出今日小结。

## 执行步骤

1. **定位文件**：
   - 用户指定了 day → 读 `days/day-XXX.md`
   - 未指定 → 读 `days/`，找最近有作答且尚未批改（无「正确答案：」）的那天；仍不明则询问

2. **读取作答**：提取每道题后 `答案：` 下方代码块中的内容。若某题为空，在文件中标注「未作答」并跳过。Part 3 无作答区，跳过。

3. **逐题批改并写入文件**：

   - **答对**：不追加任何内容，保留用户答案即可
   - **有错或可改进**：在用户答案代码块后追加：

     ```markdown
     正确答案：

     ```
     …
     ```

     解析：…（一句话说明错因或改进点，指出语法规则）
     ```

   - **已批过**（题目下已有「正确答案：」）：跳过，避免重复写入

4. **Part 3（词汇）**：无作答，跳过

5. **修改文件**：用编辑工具更新 `days/day-XXX.md`，不删除用户原答案

6. **对话汇报**（文末必出）：

   ```markdown
   ## 今日小结
   - 已批改：days/day-XXX.md（N 题追加解析）
   - 正确率：Part 4 X/18
   - 反复出现的错误模式：（列举 2–3 条）
   - 下一天建议加强：（对应 PLAN 中下一个语法单元或近期薄弱项）
   ```

## 批改原则

- 接受多种正确译法，不只给一个标准答案
- 优先纠正**中式英语**和**直译思维**，其次才是拼写
- 解析用中文，英文例句保持英文，一句话说清楚
- **保留用户原答案**，只在下方追加批改内容
- 不覆盖、不删除用户已写内容

## 示例

用户：`/review-answer day-001`

→ 读取作答 → 在错题下方追加正确答案和解析 → 对话输出今日小结
