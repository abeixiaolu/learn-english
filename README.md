# 句步 — 本地英语学习

黑白学习网页，使用已登录 ChatGPT 的官方 Codex CLI 编写课程和批改。无需模型 API Key，不接 Magpie。

## 启动

需要 Node.js 20+ 和官方 Codex CLI。在仓库目录运行：

```sh
codex login
npm start
```

登录时选择 ChatGPT。打开 http://127.0.0.1:4317。没有第三方运行依赖，无需 `npm install`。服务仅监听本机；关闭终端后，下次重新运行 `npm start`。

CLI 不在默认搜索路径时，启动前设置 `CODEX_BIN` 为可执行文件绝对路径。端口被占用时可使用 `PORT=4318 npm start`。使用 ChatGPT 账户的 Codex 权益，仍受账户额度与网络可用性限制。

## 每日学习

1. 打开最近课程，闭卷复习，再看语法和词汇。
2. 完成回译、YouTube 听力和自由表达。文字输入自动保存到本机，浏览器也保留未保存草稿。
3. 点击「批改本组」或「提交全部作答」。空题跳过；等待期间可以继续学习。
4. 查看批改并订正。原答案、每次提交、每轮批改独立保存；修改后的答案要再次提交才有新结果。
5. 在「错题与复习」里闭卷重答。当天订正不增加间隔记忆次数；正确题也安排复查。
6. 点击「编写下一课」。Codex 根据计划、历史作答、最近批改及复习队列生成课程，并搜索 YouTube 材料。生成和批改一次运行一个任务。

每次生成可能需要数分钟；10 分钟未完成会停止并显示重试提示。服务重启会将未完成任务标记失败，已保存答案保留。登录失效时重新运行 `codex login`。

听力播放器支持指定片段；有些视频会禁用嵌入，或受网络/地区限制，可点击原站入口。内容依据默认折叠，先听再核对。没有音频作答采集，因此不评估发音。

## 数据与历史

- `days/`：Day 001–025 原始 Markdown 课程、作答和批改，网页只读展示，不迁移覆盖。
- `lessons/`：新课程 JSON，固定网页按数据呈现。课程结构由 `app/schemas.mjs` 校验。
- `study-data/drafts/`：自动保存的当前作答。
- `study-data/submissions/`：提交快照，包括批改失败的提交。
- `study-data/attempts/`：历次批改及对应原答案。
- `study-data/reviews.json`：新网页课程的错题与间隔抽查队列，参考 1、3、7、14、30 天递进；原有 Markdown 错题仍在历史课程中。
- `study-data/jobs/`：生成与批改任务状态。

`study-data/` 默认不提交 Git。定期点「导出学习记录」下载 JSON；完整备份同时保留 `days/`、`lessons/` 与 `study-data/`。导出文件用于备份，目前没有网页导入功能。

课程内容和提交答案会发送给 Codex 批改或编课；登录凭据由官方 CLI 管理，不写入网页或仓库。服务校验本机来源与请求令牌。模型在临时目录、只读模式运行，服务校验返回结构后才写入学习数据。

## 验证与设计依据

运行 `npm test` 检查保存冲突、不可变提交、批改失败恢复、课程校验及复习间隔。测试使用临时目录，不写入个人学习记录。

参考 [Flashi](https://github.com/theoleuthardt/flashi) 的课程/作答/复习分离方式，并比较 [FSRS](https://github.com/open-spaced-repetition/fsrs.js) 的独立调度模型。当前使用简单可解释的间隔，不引入完整 FSRS 引擎，也不复制其代码。
