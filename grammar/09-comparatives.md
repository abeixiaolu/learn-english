# 09 — 比较级 / 最高级

## 要点

### 1. 比较级：A 比 B 更……

比较两个人、物或方案时，常用结构：

**A + be / 动词 + 比较级 + than + B**

- This option is faster than that one.
- The new API responds more quickly than the old API.
- This task is easier than the last one.

`than` 后面放被比较的对象，不要漏掉。

### 2. 形容词比较级

短形容词通常加 `-er`，较长形容词通常用 `more + 形容词`。

| 类型 | 原级 | 比较级 |
|------|------|--------|
| 一般短词 | fast | faster |
| 以 e 结尾 | large | larger |
| 辅音字母 + y | easy | easier |
| 较长形容词 | reliable | more reliable |
| 较长形容词 | expensive | more expensive |

不要把两种形式叠在一起：`more faster`、`more better` 都不对。

### 3. 不规则比较级

有些常见词不按普通规则变化，需要直接记。

| 原级 | 比较级 | 最高级 |
|------|--------|--------|
| good | better | best |
| bad | worse | worst |
| much / many | more | most |
| little | less | least |

`better` 本身已经是比较级，不要说 `more better`。

### 4. 最高级：最……

在三个或三个以上对象中选“最……”，常用结构：

**the + 最高级 + 名词 / in + 范围**

- This is the best option.
- This is the fastest way.
- She chose the most reliable service.

最高级前通常要加 `the`，因为说的是一个范围里最突出的那个。

### 5. more / most 的区别

`more` 用于比较级，表示“两者相比更……”；`most` 用于最高级，表示“最……”。

| 用法 | 例子 |
|------|------|
| more + 形容词 + than | This solution is more reliable than the old one. |
| the most + 形容词 | This is the most reliable solution. |

### 6. 常见中式错误

| 中文思维 | 错误 | 正确 |
|----------|------|------|
| 更快一点 | more faster | faster |
| 更好 | more better | better |
| 最好方案 | best option | the best option |
| 比旧版本可靠 | more reliable the old version | more reliable than the old version |
