# 10 — 将来时 will / be going to

## 要点

### 1. will：临时决定、承诺、预测

`will + 动词原形` 常用于说话时临时做决定、表达承诺，或根据判断做预测。

- I will join the call now.
- She will respond to the message later.
- This plan will need more time.

`will` 后面直接接动词原形，不要加 `to`，也不要把动词变成三单或过去式。

### 2. be going to：已有计划或明显迹象

`be going to + 动词原形` 常用于已经计划好的事情，或根据眼前证据判断很可能发生的事。

- We are going to release the hotfix tomorrow.
- She is going to prepare the report next week.
- Look at the data. This plan is going to need more time soon.

`be` 要随主语变化：`I am`、`he/she/it is`、`we/you/they are`。

### 3. will vs be going to

| 场景 | 更常用 | 例子 |
|------|--------|------|
| 临时决定 | will | I will check it now. |
| 承诺 | will | I will send the report later. |
| 已安排的计划 | be going to | We are going to upgrade the server tomorrow. |
| 有明显迹象 | be going to | This plan is going to need more time soon. |

如果中文只是说“将会/会”，先判断它是临时决定、承诺，还是已有计划。

### 4. 否定和疑问

| 类型 | 结构 | 例子 |
|------|------|------|
| will 否定 | will not / won't + 动词原形 | We won't release it today. |
| will 疑问 | Will + 主语 + 动词原形？ | Will you join the call? |
| going to 否定 | be not going to + 动词原形 | She isn't going to prepare the report today. |
| going to 疑问 | Be + 主语 + going to + 动词原形？ | Are you going to upgrade the server? |

### 5. 时间信号

将来时常和这些时间表达搭配：

- tomorrow
- next week
- later
- soon
- this afternoon
- tonight

看到这些词，不一定自动用将来时，还要看句子的意思是否真的指未来。

### 6. 形式提醒

`will` 和 `be going to` 都接动词原形，但不能叠在一起用。

- `will` 后面直接接动词原形。
- `be going to` 里的 `be` 要随主语变化。
- 否定句先确定用 `won't` 还是 `isn't / aren't going to`。
- 疑问句里，`will` 或 `be` 要放到主语前面。
