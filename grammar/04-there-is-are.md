# 04 — There is / There are

## 要点

### 1. 基本结构

用来表示「某处有……」（存在），不是「某人拥有」。

| 数量 | 肯定 | 否定 | 疑问 |
|------|------|------|------|
| 单数 / 不可数 | There **is** … | There **isn't** … / There **is no** … | **Is** there …? |
| 复数 | There **are** … | There **aren't** … / There **are no** … | **Are** there …? |

- There **is** a bug in the login flow.
- There **are** three tickets in my inbox.
- There **is** some time left.
- **Is** there a meeting this afternoon?
- There **aren't** any blockers right now.

### 2. 就近原则：看后面第一个名词

There is / are 与**紧跟其后的名词**一致：

- There **is** a laptop and two monitors on my desk.
- There **are** two monitors and a laptop on my desk.（第一个是复数 → are）

口语里有人总用 There's，但正式写作仍按单复数选。

### 3. some / any / no

| 用法 | 例子 |
|------|------|
| **some**（肯定，不定数量） | There are **some** comments on the PR. |
| **any**（否定 / 疑问） | There aren't **any** errors. / Are there **any** questions? |
| **no**（= not any） | There are **no** open issues. |

### 4. 地点放后面

英文习惯：**There is/are + 东西 + 地点**。

- ✅ There is a whiteboard **in the meeting room**.
- ❌ The meeting room has a whiteboard.（语法可通，但今天练存在句，优先 There is）
- ❌ **Here has** many people.（中式直译，错误）

### 5. 常见中式错误

| 中文思维 | 错误 | 正确 |
|----------|------|------|
| 这里有很多人 | Here has many people | There **are** many people here |
| 办公室有一台打印机 | Office has a printer | There **is** a printer in the office |
| 有会议吗？ | Has a meeting? | **Is there** a meeting? |
| 没有问题 | Has no problem | There **are no** problems / There **isn't** a problem |
| 桌上有两台显示器 | Desk has two monitors | There **are** two monitors on the desk |

### 6. There is vs have

| 含义 | 用 | 例子 |
|------|-----|------|
| 某处存在某物 | **There is/are** | There is a bug in the code. |
| 某人拥有某物 | **have / has** | I have a laptop. / She has two monitors. |

不要用「地点 + has」代替 There is/are：❌ The room has many chairs → 练存在句时写 ✅ There are many chairs in the room.
