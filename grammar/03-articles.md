# 03 — 冠词 a / an / the

## 要点

### 1. 三种情况

| 冠词 | 何时用 | 例子 |
|------|--------|------|
| **a / an** | 第一次提到、泛指「某一个」 | I need **a** laptop. |
| **the** | 双方已知、特指「那个」 | **The** laptop is on my desk. |
| **零冠词** | 复数泛指、不可数泛指、专有名词等 | I like coffee. / Engineers write code. |

### 2. a 还是 an

看后面单词的**发音**（不是拼写）：

- **a** + 辅音音：a bug, a user, a meeting
- **an** + 元音音：an engineer, an API, an hour（h 不发音）

注意：a **u**ser（/juː/ 以辅音开头）、an **h**our（/aʊ/ 以元音开头）。

### 3. 第一次提到 → a/an；再次提到 → the

- I saw **a** bug in the log. **The** bug blocks login.
- She sent **an** email. **The** email is in your inbox.

### 4. 必须用 the 的常见情况

- **双方都知道是哪个**：the office, the meeting room, the product manager
- **世界上独一无二**（日常够用的）：the sun, the internet（口语常说）
- **序数 / 最高级**：the first day, the best option
- **特指场所**：in **the** office, on **the** same team

### 5. 不用冠词（零冠词）的常见情况

- 复数泛指：Bugs happen. / Meetings start at nine.
- 不可数泛指：I need help. / She drinks coffee.
- 专有名词：Hangzhou, Alex, GitHub
- 部分固定说法：at home, at work, go to bed（整块记）

### 6. 常见中式错误

| 中文思维 | 错误 | 正确 |
|----------|------|------|
| 我是工程师 | I am engineer | I am **an** engineer |
| 在办公室 | at office | in **the** office / at **the** office |
| 产品经理（双方都知道那位） | Is product manager free? | Is **the** product manager free? |
| 写周报 | write weekly report | write **a** weekly report |
| 部署到测试环境 | deploy to test environment | deploy to **the** test environment |

### 7. 小提醒

写完句子后问自己两句：

1. 这个名词是**第一次出现、随便某一个**吗？→ 用 **a/an**
2. 听者**已经知道是哪一个**吗？→ 用 **the**
