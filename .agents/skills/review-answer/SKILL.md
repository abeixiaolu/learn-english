# 批改英语作答

批改 `days/day-XXX.md` 中的原题和答案。指定天数时使用对应文件；未指定时，找最近有未批改作答的课程，无法确定时询问。只处理用户要求的范围。保留原题、原答案、已有批改及历史记录。

## 逐题批改

1. 阅读题目和真实作答，答案可能在 `答案：` 同行、代码块中或代码块外。跳过 Part 3 词汇表；空题标记未作答，不猜测答案。
2. 在每道原题前添加唯一锚点，如 `<a name="part-1-1"></a>`，按 Part 和题号生成；已有可用锚点则复用。重复题号或已有同名锚点时添加唯一后缀，并确保每个链接对应正确题目。保留题干、题号、作答和顺序。
3. 在该题答案后写简洁批改：答对标记正确；有实质错误时给出自然正确的表达和一句中文解析；语义正确的其他表达接受，可选建议单独标记，不算错误；未答则标记未作答。必要时在原题处标记简短稳定的错误类型，供今后复习，不把题干、答案或解析复制到文末。
4. 只在练习区批改，不把答案写入 Part 2 语法讲解。再次批改时，未变化的结果和锚点不重复追加；用户新答或修改过的题重新评估，保留已有作答和批改，避免将旧结果当作新答案的结果。

例如：

````markdown
<a name="part-1-1"></a>
1. 她昨天去了公园。

答案：

```
She go to the park yesterday.
```

批改：❌ 应为 **She went to the park yesterday.** yesterday 表示过去，go 要用过去式 went。
````

## 完成情况

文件末尾只添加或更新一个 `## 完成情况`：列出已批改、正确、需订正和未作答的数量，以及对应的题号跳转链接。正确率按实际已作答且能判断的题数计算；未作答不计入分母，只有可选建议的答案计为正确。不在总结重复题干、答案、解析、错误分析或下一课建议。原有历史总结保留，不新建错题回顾。

```markdown
## 完成情况

- 已批改 2 题：正确 1，需订正 1；未作答 1。
- 正确：[Part 1-1](#part-1-1)
- 需订正：[Part 1-2](#part-1-2)
- 未作答：[Part 4-1](#part-4-1)
```

写入后检查每个链接的目标在同一文件中存在且唯一，统计与逐题批改一致。对话只报告完成情况，并用指向该课程文件及其锚点的链接帮助定位；不要在对话中重复解析或输出额外学习建议。
