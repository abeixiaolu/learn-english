# 每日英语学习

生成 `days/day-XXX.md`，帮助用户通过语法和少量实用词汇表达日常生活。使用 `templates/day-template.md` 的四部分结构，兼容 `/review-answer`。用户本次明确提出的学习内容优先。

## 准备

1. 阅读 `PLAN.md` 的学习安排、[语法推进规则](../learning-progression.md)、最近 3 天课程和最近有批改的作答、`vocabulary/learned.md`。如存在 `lessons/` 和 `study-data/attempts/`，也把它们作为历史课程和真实作答参考；不依赖服务。区分初答、订正、重复提交与未作答。已生成或已收录不等于已掌握。本文件中生活化、Markdown 和可选听力的要求优先于旧计划中相冲突的要求。
2. 根据目标语法的实际表现选一个适量的新知识点或有明确证据的巩固点。只因其他词汇、拼写或零散旧错而重复整课不合适。简要记录依据；没有足够作答时，如实说明，不假装已经掌握或遗忘。
3. 浏览最近课程的题目、例句、词汇与场景，选取不同的生活情境，如买菜做饭、交通出行、家人朋友、休闲、天气和日常安排。工作场景仅在用户要求或确有学习价值时少量使用。复习保留需要检验的知识点，但改变情境和表达任务；避免同一题换几个名词反复出现。词汇以常用、能服务当日表达为主，不规定新词数量，也不把已见词一律排除。
4. 默认比较 `days/day-XXX.md` 与存在时的 `lessons/day-XXX.json`，选最大编号之后的编号，以免批改时混淆。用户指定已存在的课程时，先说明冲突；未经明确确认不得覆盖，保留原答案和历史。不要为生成新课改写旧课程。

## 编写

- Part 1：少量闭卷混合复习，结合近期错点和以前答对的内容；用新情境检验，不把复习当成重复整课。
- Part 2：用中文讲清一个主要语法点的意思、形式、何时使用和常见误区；英文例句自然、内容区别于练习答案。设 `### 练习`，题目难度逐步上升。
- Part 3：列少量当日需要的词和常用搭配，给中文意思及不同于答案的生活例句。需要复习的旧词注明即可。
- Part 4：约 10 道回译，前几题提供必要提示，之后逐步撤去；覆盖不同生活场景和表达意图。加入一个不指定句型的真实表达任务，仍放在 Part 4 的编号题中，便于批改。
- 每道作答题下放 `答案：` 和空的围栏代码块；不预填答案或批改，不把练习答案写进讲解和词表示例。时间安排约 45 分钟，按内容灵活调整。
- 听力不是本课程的必需项。用户明确提出听力时才添加，并核实材料与实际证据，不编造听到的内容或声称未实际播放的材料已验证。

## 验证和交付

先在临时文件中写候选课程，运行：

```sh
python3 .agents/skills/daily-study/scripts/validate_lesson.py /path/to/day-XXX.md --history-dir days
```

工具检查四部分结构、编号作答题的空答案框，以及课程内和最近 3 个 Markdown 课程中的完全重复题目。检查失败时修改候选并重新运行；输出中的 SHA-256 用于对应被检查的内容。工具不能判断近义改写、语法准确性、场景是否自然、例句泄题或学习效果：逐项检查并如实报告。验证后若内容变化，重新执行检查；确认最终文件内容与已检查内容一致。通过后将新课程写入 `days/`，不要覆盖已有文件；报告课程主题、依据，并分别标明自动验证、AI 评估、人工确认和未验证的项目。课程仍是未作答状态，不把它记为已学会。

## 根据反馈改进

用户指出问题时，先判断是这次课程的修改还是长期偏好；保留原答案并按用户要求处理当前课。需要持续跟踪的问题简要记录到 [feedback.md](feedback.md)，包含问题、处理方式和验证状态，不抄录私人作答。长期问题优先用有代表性的好例子、脚本检查或已有测试约束；只有工具无法解决时才精简更新本文件。修改检查规则后，用真实历史样例和失败样例回归，记录实际运行结果；不要把用户一次性的要求永久化。
