# 产品方向（正式轨）

> 2026-10-28 确认。本文件与 `docs/GRAMMAR-ROADMAP.md` 为正式轨依据。仓库内旧网站、旧 Day/PLAN/grammar/study-data **一律视为废弃**，不做实现或内容参考。

## 客户端

- **响应式网站 + PWA**（可安装到主屏；先不求原生 App）。
- 从零建设，不演进、不复用废弃的本地学习站代码与样式约定（除非日后单独声明搬运某段工具逻辑）。

## 学习内容

- 主线：按 `GRAMMAR-ROADMAP.md` **一天一个语法点**（D001–D168）。
- 无独立复习日；复习在每日课内穿插。
- 巩固：仅用户主动发起。
- 听力：需要时用**选择题**。
- 词汇：练习顺带使用，不单开词书进度。
- 多人时：共享按 D 编号的课包；每人进度从 D001 顺序学。

## 生成与发布（关键必审）

1. **生成**：在维护者本机，用其已订阅的大模型通道完成编课（当前约定：**Cursor**、**ChatGPT**；不默认改走需另购的云端模型 API）。
2. **审核**：生成结果进入「待审」状态；**只有维护者确认通过**后，课包才可进入可发布队列。未审核内容对学员不可见。
3. **定时发布**：调度器只发布**已审核**的课包（例如按计划解锁下一 D，或把已审批次写入正式课库）。调度不负责「当场生成并直接上线」。
4. **节奏**：可超前生成并囤积已审课；学员侧仍按个人进度指针取下一课，新用户始终从 D001。

## 系统边界（讨论用草图）

| 部分 | 职责 |
|------|------|
| 学员 Web/PWA | 登录、按进度学当日课、提交作答、课内复习与听力选择 |
| 课库服务 | 存储正式课包（仅已发布）、用户进度与作答 |
| 编课工作台（可先本机） | 调本地 Cursor/ChatGPT 出稿 → 人工预览/编辑 → 标记「已审」 |
| 发布调度 | 只消费「已审」队列，定时写入正式课库或解锁 |

生成与审核允许长期留在维护者本机；学员访问的网站与课库再部署到服务器。两者用「已审课包」文件或 API 同步即可。

## 明确不做（本阶段）

- 不参考废弃站的信息架构与实现细节来「兼容旧进度」。
- 不自动把模型输出直接定时发给学员。
- 不默认上原生 iOS/Android。

## 学员端信息架构（已定）

**4 个学员页**（PWA）。**不做底部 Tab**；首页星球点进历史，另有历程入口；页间返回即可。

1. **首页 · 星球场**
   - 中央主星 = 当前学习日（语法名）
   - 周围行星 = 已完成的语法日；**可点**，进入该日历史记录
   - 主 CTA：开始今日课
   - 打卡天数极简融入（勿抢主星）
   - 星球视觉：**绘本感 2.5D 水彩球体**（高光+软阴影表体积），**不用** Three.js 真 3D

2. **做题**（**先讲再练** + **一屏一题**）
   - 先读当日语法讲解（可含单词配图卡）
   - 再进题册；一屏一题
   - 题型：**大部分手输**；少量选择/填空；听力为选择题
   - 单词卡：插图与英文词**同列水平居中**，等宽列、统一间距

3. **学习历程**
   - 藤蔓延伸；夜星 / 日云
   - 节点与藤蔓**同一手绘水彩笔触**：未完成 = **紧闭花苞**；完成 = **花朵中央包着果实**（可示意绽放动效）
   - 不做打勾圆圈节点；不做社交

4. **历史记录**（从首页点行星进入）
   - 一页展示：该日语法名、**得分**、**全部题目**（题干 / 作答 / 对错）
   - **不要**「回看全部题目」或其它二次入口按钮

编课审核、发布调度不在学员页（维护者本机/后台另做）。

### 题型原则（已定）

- **以手输为主**，用来证明会写、会用。
- **少量**单选 / 填空，降低整课疲劳、覆盖辨析点。
- 听力：选择题。
- 单词：服务当日句子；配图风格参考《小王子》（柔和线稿/水彩感、简洁意象），不是词书大全。

### UI 气质（已定）

- **暖羊皮纸质感文艺风**：可见纤维/毛边/淡污渍的暖米色纸纹；按钮与输入区有细微纹理与印压感；接近《小王子》绘本。
- 间距/边距/gap 为 **4 的倍数**且各页统一。
- 文案：Avoid unnecessary secondary labels and descriptions；布局自明，删多余副标题。
- 不做扁平互联网风、霓虹、玻璃拟态、厚塑料拟物。
- Pen 出稿迭代对齐上述约束；不参考仓库内废弃站。
