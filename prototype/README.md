# 句步响应式网页原型

当前入口：`web/index.html`。打开本地预览后可选择公司、学校、机场和自定义任务，做快速摸底，查看语法与句型路线，并体验24分钟学习闭环。

- `web/`：无构建依赖的响应式交互原型。
- `english-web.pen`：pen CLI制作的桌面与手机核心画板。
- `web/PRODUCT-DIRECTION.md`：分项诊断、场景适配、竞品官方来源及拟差异化定位。
- `web/previews/`：响应式预览与测试截图。`profile-test-*` 是代理验证操作形成的测试记录，不是真实用户水平。
- `ios-demo.html` / `english-app-ios.pen`：此前iOS版归档。

预览：在此目录启动静态服务，打开`/web/`。由于使用JavaScript模块，需要通过本地HTTP预览，而不是直接双击文件。

目前完整演示请求句课程；其余语法节点提供内容与路线预览。自定义使用通用请求模板，未接入任意情境AI生成。快速摸底仅给出少量初步证据，不对应CEFR认证。

识别少量固定请求表达、另一种有效请求及典型词形问题；未知自由回答待确认，不默认判错。语音朗读使用浏览器合成，尚无语音识别与完整语言评估。学习档案区分首次问题、提示、反馈后重试与新情境产出。间隔保持没有伪造成绩。状态在内存中，刷新清空。

没有账号、支付或长期数据保存。后续先验证教学与评估质量，再扩展课程与持久化。
